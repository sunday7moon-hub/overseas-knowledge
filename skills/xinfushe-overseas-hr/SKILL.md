# 薪福社出海服务分析

## Overview

用友薪福社（双品牌：服务品牌 **Anchor安薪** + 知识品牌 **Humance慧思**）是用友集团旗下专注于中企出海全球化2.0的人力资源服务与知识平台。

**产品策略（2026年8月起）：主推海外猎头产品，顺带做 EOR/Payroll/签证/商保，做长线运营。**
- 猎头 = 获客主入口（招聘是中企出海第一痛点，决策短、需求高频）
- EOR/Payroll 等 = 人才落地后的转化承接（招到人→需要主体雇佣/发薪/合规）

## 核心知识结构

### 1. 品牌定位
- **双品牌策略**：服务品牌 **Anchor安薪**（anchorwe.com）+ 知识品牌 **Humance慧思**（humancehr.com）
- 官网：https://www.anchorwe.com/ | https://www.humancehr.com/
- 差异化：60%海外当地服务 + 40%中企出海解决方案
- 双层架构：国内中文团队 + 海外150+国家本地团队

### 1a. Humance慧思——知识内容品牌
- 定位：全球出海人力资源知识中心，用内容驱动线索增长（inbound marketing）
- 三大内容产品：
  - **知识库**（knowledge-base）— 出海HR合规、政策解读、时事分析等每日更新文章
  - **薪酬报告**（remuneration）— 各国各行业薪酬调研报告（如马来西亚制造主管、菲律宾教育经理、日本QA工程师等）
  - **国别指南**（country-guide）— 各国雇佣合规指南（个税、签证、休假政策详解，覆盖中国台湾、蒙古、加纳、阿曼、立陶宛、克罗地亚等）
- 服务页（humancehr.com/service）露出Anchor品牌："Anchor的海外主体代表您雇佣..."，作为线索转化漏斗

### 2. 服务三层架构
- **核心产品**：海外猎头（主推）、EOR名义雇主、Payroll BPO、全球签证、全球商保
- **系统产品**：Anchor系统（薪酬/雇佣/福利/支付/合规）+ Anchor AI(YonGPT) + 自研AI智能全球猎头平台
- **定制化服务**：行业解决方案、合规咨询、薪酬体系咨询

### 3. 猎头主推产品画像（核心模块）
详见 `references/headhunting-service.md` 完整数据、`references/provider-analysis.md` 画像底座、`references/practice-baseline-2026H1.md` 实战交付基线。

**实战交付结构（要点，数值见 baseline §2–§4）**：
- **自营是交付主力**（JD 占比与交付覆盖率、首推周期均显著优于供应商）；供应商只作补充，**不承接前段生产环节**。
- **最大断点在"推荐 → 客户通过"**，不在搜索量；画像偏差是第一损耗来源。
- 岗位交付差异化明显：销售为成熟优势、技术支持为结果优势、运营供应链为潜力（Offer 未转化入职）、职能岗零转化。

**一句话定位**：不止于匹配人才，更致力于保障人才的成功落地与留存。

**解决的4大痛点**：找不到 / 找不准 / 谈不拢 / 请不来
- 找不到、找不准：目标市场人脉薄弱，触达不到被动求职的顶尖人才；只能收到大量不匹配简历
- 谈不拢、请不来：薪酬福利合同条款陷入僵局；缺乏市场薪酬数据与合规参考；目标国理解与薪酬体系错位、谈判技巧不足；信息孤岛、品牌陌生、渠道低效

**5步服务流程 + 交付物**：
```
需求沟通 → 人才寻访 → 匹配筛选 → 组织面试 → 拟录用（入职衔接）
```
| 步骤 | 服务内容 | 交付物 |
|------|---------|--------|
| 需求沟通 | 项目启动会对齐招聘目标/业务背景/薪酬福利/国家文化禁忌/职位核心要求 | 用人团队负责人亲自参与最有效 |
| 人才寻访 | JD分析、系统人才盘点、职位发布、人才意向主动问询 | 《职位需求分析表》《职位薪资水平建议报告》《职位薪资雇主成本报告》 |
| 匹配筛选 | 简历深度分析、匹配度审核、筛选跟进 | 候选人推荐报告、简历匹配分析报告（周推荐汇总+服务周报） |
| 组织面试 | 跨国面试时间沟通、安排与结果跟进 | 人才画像优化报告 |
| 拟录用 | 协助薪资谈判、录用确认、入职衔接 | 落地保障（多国雇佣实操经验兜底） |

**双层服务架构（核心差异化）**：
甲方国内招聘团队 ↔ 国内专属项目团队（纯中文/实时沟通/无时差）→ 各国一线猎头团队（新加坡/马来/...）→ 自研AI智能全球猎头平台

**擅长行业（13类）**：新能源、通信IT、跨境物流、汽车、行业SaaS、互联网、生物医药、智能制造、跨境电商、消费品、游戏、传统制造、消费电子（+其他行业），服务范围从初创团队到跨国企业。

**代表案例**：
- 某生物企业（高端生物医学成像设备）出海美国 → **14天到岗**，快速招聘避免业务受阻
- 某AI科技企业（Recurrent AI，NLP对话分析）→ **降低40%招聘成本**，外包海外招聘补足人力短板

### 4. 客户画像判断SOP（售前线索筛选）
参见 `references/provider-analysis.md` 完整决策树。
```
Q1 国家 → Q2 有主体？ → Q3 算薪方式 / Q4 有员工？ → Q5 外派还是Local？ → Q6 白领/蓝领？
```
关键判据（猎头主推视角）：
- **招聘问询/有在招海外岗位 = 猎头主推机会**（决策链短，先进口）
- **蓝领（工人）不可服务**，需特殊蓝领资质
- 有主体+外包算薪 = Payroll BPO机会（猎头落地后转化）
- 无主体+有员工 = EOR机会（猎头落地后转化）
- 外派为主 = 额外签证+商保需求

**产品组合漏斗（猎头 → 转化 → 长线运营）**：
```
海外有招聘需求 → 猎头签约（人才到岗）
    ├─ 无主体 → EOR承接雇佣（顺带转化）
    ├─ 有主体无HR算薪能力 → Payroll BPO（顺带转化）
    ├─ 外派人才 → 签证 + 商保（顺带转化）
    └─ 入职后 → 月度发薪/合规服务 = 长线运营钩子 → 复购扩招
```

### 5. 出海阶段维度（目标客户判断）

第一阶段：产品出海（参展/获订单）→ ❌ 非核心
第二阶段：渠道出海（派人发展渠道）→ ✅ 核心目标
第三阶段：产能/品牌出海（设厂/建团队）→ ✅ 核心目标

| 岗位组 | 定位 | 打法 |
|--------|------|------|

### 8b. 服务边界：不承接清单与转化路径

产品矩阵只有 5 大核心（猎头/EOR/Payroll/签证/商保），**公司注册、主体设立、ODI 备案、工商财税代理、资质认证均不在范围内**。

| 客户问到的需求 | 是否承接 | 标准转化路径 |
|---------|---------|------------|
| **海外公司注册 / 主体设立** | ❌ 不承接 | ① 短期用 **EOR** 免注册合规雇人（最快路径）；② 注册完成后切 **Payroll BPO** 承接发薪个税社保 |
| ODI / 境外投资备案 | ❌ 不承接 | 转介用友集团其他业务线或第三方（需内部先确认渠道） |
| 海外记账报税（非薪酬类） | ❌ 不承接 | Payroll BPO 仅覆盖薪酬个税社保申报，不含企业财税 |
| 商标 / 专利 / 行业资质认证 | ❌ 不承接 | 转介 |
| 蓝领 / 劳务批量派遣 | ❌ 不承接 | 需特殊资质，见模块8 |

**客户问"能不能帮忙注册 XX 国公司"时的三追问**（判断真实需求）：
1. 为什么现在要注册？—— 是雇人、签合同、还是开票收款？
2. 首批几个人、什么时候到岗？
3. 注册下来后薪酬社保谁算？有没有 Local HR？

> 判断原则：**注册公司只是手段，雇人落地才是需求**。能绕开注册就用 EOR 绕开（决策快、无主体成本）；绕不开就等主体下来后切 Payroll；无论哪种，只要"要招人"就先上猎头。
> 注意：小国/非重点国（如内容库无该国国别指南）交付能力需与交付侧二次确认后再对客承诺。

### 9b. 实战交付纪律（2026-09-16 新增）

**六项必核字段（推荐前强制）**：**技能 / 语言 / 薪资 / 年龄身份 / 地点搬迁 / 职业动机**——六项任一未核，画像偏差将直接转化为损耗。

**三条损耗规律（数值见 `practice-baseline-2026H1.md` §9–§10）**：
1. **画像偏差是第一损耗**：内审不通过的主因依次是技能不符、原因未明确、薪资超预算、年龄/身份、语言不符。
2. **候选人放弃是第二损耗源**：失联/主动放弃占比最高，其次是地点搬迁与职业发展不匹配 → 建联阶段就要确认搬迁意愿与职业动机。
3. **客户侧取消产生流程损耗**：客户因战略/计划调整主动关闭 JD 会造成候选人流程中断，最高损耗环节是"客户评估后待反馈" → 须建**稳定 JD 池**平滑需求波动。

**风险画像**：**中文/华人要求岗属"高需求弱转化"**——客户通过、面试通过均低于对照组，Offer 难以转化入职 → 接单前须核验候选人的搬迁意愿与当地薪酬匹配度。

### 10. 成功与失败案例

**猎头成功案例：**
- 某生物企业（高端生物医学成像设备，脑科学院士创立，2024获美国订单）→ 出海美国猎头，**14天到岗**
- 某AI科技企业（Recurrent AI，NLP对话分析）→ 外包海外招聘，**降40%招聘成本**

**EOR成功案例：**
- 某头部科技企业（移动办公）→ 日本30人同步入职，无Local HR，EOR全包
- 某基因检测公司 → EOR覆盖10国（巴西、哥伦、马来、印度等），10-30人规模

**失败案例（关键学习）：**
- 某跨境物流 → EOR成本占工资一半 → 客户选了RPO
- 某机械制造 → 老板对海外成本无认知 → 业务搁置

### 17. Q3 业务计划与扩展路线（2026-09-16 新增）

> 完整计划、指标与扩展方向见 `references/q3-plan-roadmap.md`。**计划值是目标不是成果**，不得作为既有战绩对外表述。

**总纲**：AI 作为核心生产力贯穿**获客、服务与交付**；PLG 作为产品经营理念。**猎头是 AI 交付能力的首个落地场景**。

**猎头线——从 5 个断点到四组动作**：

| 断点 | Q3 解法 |
|------|---------|
| ① 需求输入波动大（自有客户 JD 不稳） | **拓展需求来源**：入驻猎头平台 + 合作渠道 + 内部业务线，建立可持续 JD 池 |
| ② 候选人沟通自动化不足 | **扩大人才供给**：新渠道 + LinkedIn 账号池 + 每日批量建联 |
| ③ 简历内审通过比例低（事实与综合判断混合） | **双 Agent 独立输出**（匹配得分 Agent + 综合评价 Agent）+ **对抗复核** |
| ④ 推荐表达弱（简历通过率低） | **30 秒推荐报告**：报告与简历合一，突出匹配结论、关键证据、风险项 |
| ⑤ 客户反馈推进不稳（长期待反馈） | **推荐与追反馈 Agent**：触达、提醒、状态记录、升级处理 |

**验收四条主线**：需求来源（可交付 JD）→ 人才供给（渠道/账号/日建联）→ Agent 化与质量（复核后内审通过率、自动获资料率、报告合一）→ 交付结果（月度简历交付/客户通过率/Offer/入职）。具体数值见 roadmap §2.3。

**获客线——注册断点与三承接**：内容站与搜索持续带来访问，但缺"价值交换 + 持续跟进"→ 用**社群（信任培育）+ 工具（留资转化）+ SDR（高意向跟进）**补齐承接机制。指标维度：内容获客 / 大数据获客（企业名录撞库）/ 转化与激活 / 留存与运营（见 roadmap §1.3）。

**扩展路线（5 个方向）**：
1. **需求来源扩展**：自有客户 JD → 猎头平台 / 合作渠道 / 集团内部业务线，形成可持续 JD 池
2. **人才供给扩展**：账号池与渠道规模化，形成稳定候选人入口
3. **生产自动化扩展**：意向询问 → 建联 → 资料获取 → 内审 → 推荐 → 追反馈全链 Agent 化，Pipeline 视图与全生命周期管理上线
4. **区域扩展**：巩固"东南亚规模核 + 欧洲质量核"，把欧洲后段转化方法向东南亚复制
5. **转化承接扩展**：工具/社群/SDR 三承接 → 猎头落地后转 EOR/Payroll/签证/商保 → 月度长线运营

**人工质量门（Q3 仍保留，勿宣称全自动）**：需求画像、寻源策略、简历内审、面试推进、Offer 谈薪由人工判断并验收。

## 使用方法

1. 用户提出相关问题时，必须参考本技能中的品牌定位、产品矩阵和客户画像信息来回答
2. 猎头是主推产品——涉及招聘/找人的场景先推猎头，EOR/Payroll/签证/商保作为落地转化
3. 如需完整数据支撑，读取 `references/headhunting-service.md` 或 `references/provider-analysis.md`
4. 对比分析时，注意Anchor的差异化定位（60%海外+40%中企）
5. 售前场景下，严格按照SOP决策树判断客户需求匹配度
6. 目标客户判断四维度：出海阶段→行业→组织类型→人群特征
7. 非目标客户要果断排除，参考失败案例作为销售培训素材
8. 涉及竞品工具对标、工具市场获客规划、MCP 化优先级判断时，联动加载 `overseas-hr-benchmark` 技能获取方法论与八家对标结论
9. **数据类问题分流**：问"做过什么/哪类客户转化好/数据是多少"读 `practice-baseline-2026H1.md`；问"Q3 目标/怎么打/往哪扩"读 `q3-plan-roadmap.md`。**两文件数值不得混用**（历史事实 vs 计划目标）
10. **画像类回答按优先级断层级输出**：行业按 P0/P1/P2、区域按规模核/质量核/储备、岗位按成熟/结果/潜力/不主攻；涉及岗位推荐时主动提示"职能岗不主攻、中文要求岗需先核搬迁与薪酬"
11. **计划类内容对客谨慎**：Q3 指标属内部规划，对客沟通只说能力与方向，不承诺具体数字；自动化成功率（任务执行口径）不得表述为业务转化率
