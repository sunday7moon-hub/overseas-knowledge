# 薪福社出海服务分析

## Overview

用友薪福社（双品牌：服务品牌 **Anchor安薪** + 知识品牌 **Humance慧思**）是用友集团旗下专注于中企出海全球化2.0的人力资源服务与知识平台。本技能提供完整的竞品/合作伙伴分析知识库，涵盖服务矩阵、多维度客户画像（出海阶段/行业/组织/人群）、客户识别信号、竞争壁垒、行业方案、成功/失败案例等。

当用户询问以下话题时加载本技能：
- 用友薪福社 / Anchor安薪 / Humance慧思 / 用友出海
- 出海人力资源服务对比（EOR/Payroll/猎头/签证/商保）
- 客户画像和售前需求判断
- 中企出海HR竞品分析
- 目标客户筛选和商机判断
- 全球出海HR知识库 / 薪酬报告 / 国别指南

## 核心知识结构

### 1. 品牌定位
- **双品牌策略**：服务品牌 **Anchor安薪**（anchorwe.com）+ 知识品牌 **Humance慧思**（humancehr.com）
- 官网：https://www.anchorwe.com/ | https://www.humancehr.com/
- 差异化：60%海外当地服务 + 40%中企出海解决方案
- 双层架构：国内中文团队 + 海外150+国家本地团队

### 1a. Humance慧思——知识内容品牌
- 定位：全球出海人力资源知识中心，用内容驱动线索增长（inbound marketing）
- 三大内容产品：
  - **知识库**（knowledge-base）— 出海HR合规、政策解读、时事分析等每日更新文章
  - **薪酬报告**（remuneration）— 各国各行业薪酬调研报告（如马来西亚制造主管、菲律宾教育经理、日本QA工程师等）
  - **国别指南**（country-guide）— 各国雇佣合规指南（个税、签证、休假政策详解，覆盖中国台湾、蒙古、加纳、阿曼、立陶宛、克罗地亚等）
- 服务页（humancehr.com/service）露出Anchor品牌："Anchor的海外主体代表您雇佣..."，作为线索转化漏斗

### 2. 服务三层架构
- **核心产品**：EOR名义雇主、Payroll BPO、全球猎头、全球签证、全球商保
- **系统产品**：Anchor系统（薪酬/雇佣/福利/支付/合规）+ Anchor AI(YonGPT)
- **定制化服务**：行业解决方案、合规咨询、薪酬体系咨询

### 3. 客户画像判断SOP（售前线索筛选）
参见 `references/provider-analysis.md` 完整决策树。
```
Q1 国家 → Q2 有主体？ → Q3 算薪方式 / Q4 有员工？ → Q5 外派还是Local？ → Q6 白领/蓝领？
```

关键判据：
- **蓝领（工人）不可服务**，需特殊蓝领资质
- 有主体+外包算薪 = Payroll BPO机会
- 无主体+有员工 = EOR机会
- 外派为主 = 额外签证+商保需求

### 4. 出海阶段维度（目标客户判断）
```
第一阶段：产品出海（参展/获订单）→ ❌ 非核心
第二阶段：渠道出海（派人发展渠道）→ ✅ 核心目标
第三阶段：产能/品牌出海（设厂/建团队）→ ✅ 核心目标
```
- **核心目标客户**集中在渠道出海和产能/品牌出海阶段
- 产品出海阶段海外不需要人，非目标

### 6. 目标客户特征画像

| 维度 | 画像描述 |
|------|---------|
| **出海模式** | 营销、服务出海为主（轻资产出海） |
| **岗位类型** | 白领（高薪、高技能）为主 |
| **业务模式** | To B为主是目标客户 |
| **决策权** | 管理（采购）权在国内为主 |
| **国家数量** | 出海国家较多，需要多国统一管理 |
| **价值取向** | 注重服务与体验，成本靠后 |
| **人群特征** | 专业程度要求高、工资相对较高、长期深耕本土 |

### 7. 非目标客户（4类明确排除）

| 类型 | 排除原因 |
|------|---------|
| 跨境电商小商家、贸易公司 | 只是产品出海，海外不需要人 |
| 制造业海外会展产品推广 | 不常驻，短签即回 |
| 国内可远程交付的服务公司 | 远程交付无需海外人员 |
| 批量劳务/建筑/工厂工人外派 | 劳务外派需特殊资质，当地不交社保 |

### 8. 客户识别信号

**公开信号（企业动向）：**
- 招聘信息异动 → 大量发布海外职位
- 企业扩张动作 → 新闻中"海外子公司注册""海外建厂"
- 融资信号 → AI/新闻/海关/投融资数据

**询问信号（主动咨询）：**
- 合规风险咨询 → "海外雇佣有哪些风险？"
- 薪酬福利调研 → "某国的平均薪资？"
- 人事手续咨询 → "如何办理海外工作签证？"

### 9. 成功与失败案例

**成功案例：**
- 某头部科技企业（移动办公）→ 日本30人同步入职，无Local HR，EOR全包
- 某基因检测公司 → EOR覆盖10国（巴西、哥伦、马来、印度等），10-30人规模

**失败案例（关键学习）：**
- 某跨境物流 → EOR成本占工资一半 → 客户选了RPO
- 某机械制造 → 老板对海外成本无认知 → 业务搁置
