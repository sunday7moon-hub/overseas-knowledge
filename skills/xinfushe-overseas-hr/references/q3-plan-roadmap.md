# 猎头与获客 Q3 计划及扩展路线（2026Q3）

> **本文件是 Q3 计划与扩展方向的唯一真相源。** 其他文件只做摘要与指针，不得复制本文件数值。
> 数据来源：《2026Q3中台研发部规划》（2026-08，郭鹏）第 9、22–28 页。
> 版本：v1.0（2026-09-16）
> 口径提醒：自动化成功率为**任务执行口径**，不等同于业务转化率。

---

## 0. 部门定位（计划总纲）

**智能业务部（拟）**：AI 作为核心生产力贯穿**获客、服务与交付**；PLG 作为产品经营与增长理念。

| 支柱 | 内容 |
|---|---|
| AI 核心驱动 | 数据获取 · 内容生成 · 交付 Agent |
| 01 获客转化 | 内容获客与大数据获客双路径引流，社群与产品工具承接转化 |
| 02 智能服务 | AI 处理标准化服务与运营，人工聚焦关键判断、客户关系、异常升级 |
| 03 智能交付 | AI 承担寻源、人才画像、匹配、建联与推荐报告生成，**现阶段聚焦猎头服务** |
| PLG 飞轮 | 用户价值 → 产品体验 → 使用转化 → 口碑传播 → 持续增长 |

**结论**：猎头是 AI 交付能力的**首个落地场景**，也是获客主入口——Q3 的扩展动作都围绕"稳定需求 + 稳定供给 + Agent 化生产 + 结果验证"展开。

## 1. 获客线：问题 → 计划 → 指标

### 1.1 当前断点（问题分析）

**核心判断**：自动化已解决内容生产与流量导入，但**访问用户缺少明确的价值交换与持续跟进**，尚未形成稳定的"访问 → 注册"链路。

| 断点 | 表现 |
|---|---|
| 流量已经进入 | 内容站、搜索渠道、自动化分发持续带来访问，但单纯浏览难自然转化为注册/留资/咨询 |
| **注册断点** | 缺少承接机制 |

**补充三种有效转化手段**：社群（信任培育）、工具（价值交换，推动注册留资）、SDR（识别高意向行为主动跟进）。

> 阶段判断：自动化已解决内容供给与分发效率，但**社群互动率仅 8%、92% 用户沉默**；下一步从"自动分发"转向"工具承接 + 用户分层 + SDR 跟进"的转化闭环。

### 1.2 Q3 获客计划

| # | 方向 | 动作 |
|---|---|---|
| 01 | 内容获客（稳定自然流量） | 持续生产专业内容与知识数据产品；补齐访问、阅读、收藏、下载统计；内容站 DAU 稳定在 200 以上 |
| 02 | 大数据获客（用好现有数据） | 以 **4,028 家企业名录**为数据底座；在外部渠道侧**撞库**识别可触达联系人；沉淀撞库结果形成定向触达清单 |
| 03 | 私域转化与增长激活 | 社群内容培育 + 工具促进留资与行为；完成 **≥3 个增长实验**；日注册 ≥2、7 日激活率 >10%、老用户 WAU >20 |

### 1.3 Q3 获客指标（验收标准）

| 指标维度 | 关键能力 / 动作 | Q3 验收标准 |
|---|---|---|
| 内容获客 | 专业内容与知识数据产品｜自然流量 | DAU ≥200｜日注册 ≥2 |
| 大数据获客 | 4,028 家企业数据｜渠道侧撞库 | 不新增数据迭代｜撞库可追踪｜定向清单 |
| 转化与激活 | 社群运营｜工具转化｜MCP 引流 | ≥3 个增长实验｜7 日激活率 >10% |
| 留存与运营 | 收藏｜订阅｜下载｜老用户运营 | 老用户 WAU >20｜关键行为可统计 |

- **增长实验范围**：MCP 引流、工具转化及用户激活策略，记录来源、行为和转化结果。
- **管理方式**：每周查看来源与实验进度，每月复盘 DAU、注册、激活与留存。
- **关键闭环**：内容来源可统计｜渠道撞库可追踪｜私域转化、用户激活与留存一体化运营。

## 2. 猎头线：5 个断点 → Q3 四组动作 → 指标

### 2.1 五个断点（问题分析）

**阶段判断**：需求波动与关键环节自动化不足同时存在——前端缺少稳定岗位供给，中后段的信息判断、推荐表达与反馈推进仍依赖人工。

| # | 断点 | 现状 | 解法方向 |
|---|---|---|---|
| 01 | **需求输入**：需求波动较大 | 自有客户 JD 不稳定，交付产能缺少持续需求承接 | **扩展猎头平台、合作渠道与内部业务线等岗位来源，建立可持续 JD 池** |
| 02 | **候选人沟通**：自动沟通占比低 | 意向询问、建联、简历获取仍有较多人工操作 | 批量完成意向询问、建立联与简历/薪资资料获取 |
| 03 | **简历内审**：内审通过比例低 | 事实匹配与综合判断混合，评价标准不稳定 | **双 Agent 独立输出**：匹配得分 Agent（事实匹配）+ 综合评价 Agent（风险与推荐判断） |
| 04 | **推荐表达**：简历通过率低 | 有效信息传递不足，客户难以快速识别候选人价值 | **30 秒推荐报告**：报告与简历合一，突出匹配结论、关键证据、风险项与推荐理由 |
| 05 | **客户反馈**：简历反馈率低 | 人工推荐与追反馈不稳定，候选人长期停留在待反馈状态 | **推荐与追反馈 Agent**：完成推荐触达、反馈提醒、状态记录与升级处理 |

**改进主线**：扩大需求来源 → 提升候选人沟通自动化 → 双 Agent 提高内审质量 → 30 秒传递推荐价值 → Agent 持续推进客户反馈。

### 2.2 Q3 猎头计划（需求—供给—生产—结果）

| # | 方向 | 动作 |
|---|---|---|
| 01 | **拓展需求来源**（稳定可交付岗位） | 入驻猎头平台，建立持续岗位来源；获取 **10 个可交付 JD** 需求 |
| 02 | **扩大人才供给**（稳定候选人入口） | 拓展 **1 条**招聘渠道并完成技术验证；LinkedIn 账号池扩至 **20 个**；每日可建联 **>90**；至少 **10 个账号稳定 60 天** |
| 03 | **贯通 Agent 化交付**（对抗复核提质量） | 匹配得分与综合评价 Agent 独立输出；**对抗复核后内审通过率 ≥90%**；自动获简历/薪资 **≥70%**；报告简历合一 |
| 04 | **完成交付结果**（以结果验证价值） | 月交付候选人简历 **≥100 份**；客户简历通过率 **>30%**；完成 **12 个 Offer、4 个入职** |

### 2.3 Q3 猎头指标（验收标准）

| 指标维度 | 关键能力 / 动作 | Q3 验收标准 |
|---|---|---|
| 需求来源 | 猎头平台入驻与岗位获取 | **10 个可交付 JD** |
| 人才供给 | 新增渠道｜LinkedIn 账号池｜候选人建联 | 1 条渠道｜20 个账号｜>90 人/日｜≥10 个稳定 60 天 |
| Agent 化与质量 | 匹配得分｜综合评价｜对抗复核｜自动资料获取 | 意向→内审 >5%｜复核后内审 ≥90%｜自动获资料 ≥70%｜报告合一 100% |
| 交付结果 | 月度简历交付｜客户通过｜Offer 与入职 | ≥100 份/月｜客户通过 >30%｜12 Offer｜4 入职 |

- **验收逻辑**：周看过程｜月看交付｜季看 Offer 与入职。
- **系统验收项**：全生命周期管理、Pipeline 视图、推荐报告简历合一、企业微信自动化上线。
- **人工质量门**（不可自动化）：需求画像、寻源策略、简历内审、面试推进、Offer 谈薪由人工判断并验收。

## 3. 交付流程基线（一个 JD、一条连续流程、两个协同泳道）

```
前道｜客户与质量                    后道｜候选人生产
01 JD采集·需求澄清（人工）            02 人才画像·寻源策略（人工）
07 简历与报告内审（人工）  ←────────  03 搜索寻源（Sourcing Agent）
08 推荐客户·反馈追踪（Delivery Agent） 04 长名单匹配（Matching Agent）
09 面试推进（人工）                   05 候选人建联（Engagement Agent）
10 Offer谈薪·入职（人工）             06 生成推荐报告（Report Agent）
```

- **交接关系**：前道完成 JD 采集与需求澄清 → 后道形成画像、寻源并生产候选人 → 后道形成推荐报告 → 前道内审并推动客户决策。
- **人工质量门**：需求画像、寻源策略、简历内审、面试与 Offer 由人工判断；Agent 生产链为 **Sourcing → Matching → Engagement → Report → Delivery**。
- **关键交付物**（前道）：需求访谈纪要｜内审结论｜推荐记录与客户反馈｜面试安排与反馈｜Offer 与入职记录。
- **关键交付物**（后道）：人才画像与寻访建议｜候选人搜索池｜候选人长名单｜简历/意向/薪资信息｜推荐报告。

## 4. 扩展方向（由 Q3 计划外推的路线）

| 维度 | 现状（2026H1） | Q3 扩展 | 中期延伸方向 |
|---|---|---|---|
| **需求来源** | 依赖自有客户 JD，波动大 | 入驻猎头平台 → 10 个可交付 JD | 平台 + 合作渠道 + 集团内部业务线，形成**可持续 JD 池** |
| **人才供给** | 账号与渠道有限，日建联受限 | 1 条新渠道 + LinkedIn 20 账号 + 日建联 >90 | 账号池规模化 + 多渠道并行，形成**稳定候选人入口** |
| **生产自动化** | 意向询问/建联/资料获取人工占比高 | 自动获简历/薪资 ≥70%、报告简历合一 | 双 Agent 对抗复核 → 内审 ≥90% → Pipeline 全流程自动化 |
| **质量体系** | 内审标准不稳定 | 匹配得分 + 综合评价双 Agent 独立输出 | 结构化原因强制记录（对齐损耗基线 §9） |
| **区域布局** | 东南亚规模核、欧洲质量核 | 巩固双核，不打满储备区 | 欧洲后段转化方法向东南亚复制，提升规模核的面试通过率 |
| **转化承接** | 猎头单点签约 | 工具 + 社群 + SDR 三承接 | 猎头 → EOR/Payroll/签证/商保组合转化 + 月度长线运营 |
| **获客数据** | 4,028 企业名录 | 渠道侧撞库 → 定向清单 | 撞库结果沉淀为可追踪的线索资产，反哺画像模型 |
| **中台支撑** | 结算/开票能力已升级 | 系统开票扩面 + 超时预警 | 系统开票覆盖扩大（当前 33.7%）+ 结算 ≤40 分钟占比维持高位 |
