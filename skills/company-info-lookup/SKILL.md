# 企业信息查询（Company Info Lookup）

## Overview

根据企业名称判断企业的**所在城市、省份、大区、行业**，输出到 Excel 表格新增列。核心方法：先从公司名提取信息（城市/省份/品牌知识库），再通过天眼查/企查查等企业网站**批量搜索验证**，特别是对上市公司可直接获取权威行业分类。

## 工作流

### Step 1: 读取数据

- 用 Python openpyxl 读取 Excel，提取公司名单（A列）
- 确认列结构：若 C 列已有"地点"，注意这通常是**职位地点**而非公司总部（如"印度尼西亚""越南"），只能作为兜底参考
- 若表格已在编辑器打开（有 file_id），通过 `tencent-local-office-edit` skill 的编辑器通道读写，保持用户实时可见

### Step 2: 公司名初步判断（先跑一遍，减少搜索量）

按优先级提取：

1. **城市名直接匹配**：公司名含"XX市"或城市名（如"南京科思化学"→南京）→ 查 `references/city-province-region.md` 城市→省份→大区映射表
2. **省份名匹配**：公司名含"广东/浙江/江苏"等 → 省份级
3. **品牌知识库**：知名品牌映射（如"科大讯飞"→合肥、"中联重科"→长沙、"拼多多"→上海）
4. **海外关键词**：含"越南/泰国/美国/马来西亚"等 → 海外

大区分区规则：
- 华北：北京、天津、河北、山西、内蒙古
- 东北：辽宁、吉林、黑龙江
- 华东：上海、江苏、浙江、安徽、福建、江西、山东
- 华中：河南、湖北、湖南
- 珠三角：广州、深圳、东莞、佛山、珠海、中山、惠州、江门、肇庆（广东9市）
- 华南：广西、海南、广东其他城市
- 西南：重庆、四川、贵州、云南、西藏
- 西北：陕西、甘肃、宁夏、新疆、青海
- 海外：其他国家
- 港澳台：香港、澳门、台湾

### Step 3: 批量搜索验证（重点）

对上市公司和不确定的公司，用 WebSearch 搜索"公司名 + 主营业务/行业/天眼查"。

**高效搜索技巧：**
- 每批搜索 5-8 家公司（query_keyword_groups 最多 5 组）
- 上市公司信息最准：搜索结果中"申万一级行业""主营业务""所属地域"字段直接可用
- 天眼查页面（tianyancha.com）会同时列出多家相关公司信息，一次搜索可覆盖多家
- 搜索确认后**修正**初步判断（常见错误：品牌总部 vs 注册地混淆、公司名含地名但总部在别处）

**行业判断兜底（无搜索结果的名称推断）：**
- "XX贸易/商贸/进出口" → 贸易/商贸
- "XX物流/供应链/货运" → 物流
- "XX科技/信息/软件" → 科技/软件（需进一步确认细分）
- "XX人力资源/企业管理" → 人力资源服务
- "XX机械/装备/制造" → 机械设备/制造
- "XX医疗/生物" → 医疗健康/生物科技
- "XX能源/电力" → 能源

### Step 4: 写入表格

- 新增列：所在城市、大区、省份、行业（通常依次排在已有数据之后）
- 通过编辑器通道写入时注意：
  - `sheet_set_range_value` 用 row/col（0-based）+ value_type=STRING
  - 表头单独写 row=0
  - **保存失败"Export file is occupied"** = WPS 占用文件，等待 2-3 秒重试即可
  - 文件被重新打开后 file_id 会变化，先 `get_pool_status` 获取最新 file_id
- 写入后验证：抽查若干行确认数据正确

## 数据来源优先级

1. **上市公司**：东方财富 F10 / 股票行情网站（行业分类最权威）
2. **天眼查/企查查**：企业注册地、行业、经营范围
3. **百度百科/企业官网**：总部地点、业务简介
4. **公司名推断**：仅作兜底，标注为推断

## 常见坑

- **C列"地点"≠总部**：表格中的地点列多为招聘职位地点（海外国家），不能直接当公司总部
- **注册地与总部不同**：如万兴科技注册地西藏但总部深圳，以实际总部为准
- **"XX分公司"归属母公司**：如"北京山海图科技有限公司西安分公司"→ 总部在北京
- **县级市名称**：丹阳（江苏）、浏阳（湖南）、铁力（黑龙江）等需加入城市映射，否则会被误判
