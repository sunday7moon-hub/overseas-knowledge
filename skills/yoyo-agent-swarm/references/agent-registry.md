## 0. 设计原则

| 原则 | 说明 |
|------|------|
| **上下文隔离** | 每个 Agent 独占一套「飞书表 + 脚本 + 记忆文件」，禁止跨 Agent 写别人的表 |
| **触发独立** | 每个 Agent 有独立 cron 时间点，互不抢占 |
| **失败隔离** | 单 Agent 失败不影响其他 Agent；失败由 QC Auditor 捕获并通知 Yoyo |
| **幂等可重跑** | 任一 Agent 重复执行同一天，结果应一致（30天/60天去重窗口保证） |
| **宁缺毋滥** | 采集类 Agent 找不到合规来源 → 记 `no_result`，严禁 AI 编撰/以法代模 |
| **只汇报不越权** | 除明确授权外，Agent 不得修改其他 Agent 的配置与自动化 |
| **默认无生产权限** | 全部 Agent **默认无线上生产写权限**（Strapi prod / Anchor DB）；拿到写 Token 也须 Yoyo 在场确认才可写；越界清单见 §0.1 |
