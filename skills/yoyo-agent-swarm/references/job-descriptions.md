# 一页纸岗位说明书（Job Descriptions）· 第一批 4 份

> **用途**：QoderWork 借鉴「方向1 流程→岗位」落地物。给 4 个高复用 Agent 补 QoderWake 式「一页纸岗位说明书」——出问题能定位到"人"而非"哪个 cron 又挂了"；对外演示时讲的是**团队**不是脚本。
> **格式**：姓名 / 对外岗位名 / 一句话定位 / 职责 / 输入源 / 产物标准（数量+质量门禁+验收人）/ 上下游 / **工具白名单（档位+可调用工具+禁止工具）** / **工作区路径** / 红线。
> **状态**：2026-09-09 第一批 4 份（P0）。2026-09-09 15:45 补齐「工具白名单 + 工作区路径」两栏（对标 Accio 工具 4 档）。后续按同一模板扩展 A1–A15 全量。
> **关联**：真相源 registry = `references/agent-registry.md`；借鉴对照 = `references/qoderwork-borrowing.md` §2 方向1。

### 工具档位定义（对标 Accio Work 工具 4 档）

| 档位 | 含义 | 适用 |
|---|---|---|
| **Minimal 只读** | 只读 + 只产出判断，**无任何写入权** | QC / 复核类 Agent 的标准形态 |
| **Standard 标准** | 可读可写，但写入范围限定在指定表/目录 | 绝大多数生产 Agent |
| **Full 全量** | 可跨表/跨目录写、可调用外部 API | 高信任 Agent，须逐项列明 |
| **TL 组长** | Full + 团队管理权（派活/回收/校验/退回） | 仅 Agent Manager |

> **规则**：① 默认给 Standard，不要随手给 Full；② QC 类一律 Minimal 只读；③ 档位写进岗位说明书 = TL 路由时可据此判断谁能领什么活。
