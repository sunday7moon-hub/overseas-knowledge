# AEO 布局方案 — 出海HR内容的答案引擎优化

> 基于 Ethan Smith（Graphite CEO）AEO 方法论 + Humance 现有内容资产定制
> 核心原则：**在答案引擎里，赢的不是排名第一，而是被跨来源引用的次数最多**

MCP Server 提供 5 个工具：`search_regulations` / `get_regulation_detail` / `get_country_baseline` / `submit_lead` / `save_aeo_content`

后端数据库 3 张核心表：`regulations`（法规库）/ `country_baselines`（国家基线）/ `aeo_qa`（AEO内容）

这款工具的核心设计原则：
1. **工具即内容**——每次用户使用都自动生成结构化 Q&A，存入网站 + 加 FAQ Schema
2. **自检过程=内容生产**——用户每答一题，系统自动产出一条「问题+答案」对
3. **法规监控=内容更新**——每次推送法规变更，同步生成「变更 Q&A」
4. **留资即线索**——预览报告→注册下载→转销售跟进

## 三、核心认知

### 2.1 与传统 SEO 的区别

| 维度 | SEO | AEO |
|:----|:---|:----|
| 目标 | 排名第一 | **被引用最多** |
| 查询长度 | ~6 个词 | **~25 个词** |
| 关键指标 | 点击率/排名 | **跨源引用次数** |
| 内容形态 | 关键词密度 | **结构化问答** |
| 转化率 | 基准 | **LLM 流量是搜索的 6 倍**（Webflow 实证） |

### 2.2 Humance 的 AEO 优势

- ✅ 出海合规本来就是长尾问答场景（用户问 AI 的问题很具体）
- ✅ 法规/国别内容独家性强，难以被替代
- ✅ 知识库天然就是「帮助中心」——文章提到的 AEO 秘密武器
- ✅ B2B 服务，LLM 带来的流量转化率远高于搜索

## 三、执行流程

### Step 1：建立问题池

从以下数据源提取用户真实在问的出海合规问题：

| 数据源 | 提取方法 |
|:------|:--------|
| 百度统计搜索词 | 拉取 `source/searchword/a` 接口，提取「其他」以外的可识别词 |
| 注册来源 URL | 从 `register_page` 的 `redirect` 参数提取用户想看的页面 |
| 国别指南/法规页面访问 | 从百度统计 TOP 页面提取高频访问的 URL |
| 二维码扫码数据 | 从 Wechat Qrcode Tracking 提取用户扫码时的页面 URL |
| 客服/销售记录 | 手动整理客户常问的问题 |

**示例问题池（出海HR场景）：**
```
Q: 中国公司在印尼雇佣员工需要缴纳哪些社保？
Q: 马来西亚外劳工作签证办理流程是什么？
Q: 美国劳工标准法案对中资企业有什么影响？
Q: 波兰最低工资2026年是多少？
Q: 沙特劳动法对员工辞退补偿的规定？
Q: 新加坡雇佣外籍员工的EP签证门槛是多少？
Q: 在越南设立公司需要哪些步骤？
```

### Step 2：内容改造 — Q&A 结构化

将**段落式文章**改造成 **AI 友好的问答结构**：

**改造前（段落式）：**
```
【正文】波兰劳动法解读...
波兰劳动法规定了雇佣关系中的权利义务...
最低工资标准为...
```

**改造后（Q&A 结构）：**
```
标题：中国企业在波兰用工：劳动法、最低工资与辞退补偿全解读

Q：波兰的劳动法主要包含哪些内容？
A：[完整回答，包含具体条款编号]

Q：2026年波兰最低工资标准是多少？
A：[具体数字 + 计算方式]

Q：波兰员工辞退补偿如何计算？
A：[分在职年限说明]

Q：波兰的工作签证有哪些类型？
A：[类型对比 + 申请条件]
```

**每篇文章覆盖 8-10 个相关长尾问句**，一篇=10个被引机会。

### Step 3：FAQ Schema 标记

在文章 `<head>` 或页面底部添加结构化数据：

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "波兰的劳动法主要包含哪些内容？",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "波兰劳动法（Labour Code）规定了..."
      }
    },
    {
      "@type": "Question",
      "name": "2026年波兰最低工资标准是多少？",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "2026年波兰最低工资为..."
      }
    }
  ]
}
```

### Step 4：多源引用布局

**核心原则**：同一套内容，布局到多个平台 → AI 在多个来源都看到你 → 被引用概率指数级上升。

| 平台 | 内容形式 | 优先级 |
|:----|:--------|:------|
| **humancehr.com** | 深度完整版（Q&A 结构） | 🚨 主站 |
| **知乎专栏** | 同一内容的精简问答版 | 🔥 P1 |
| **微信公众号** | 出海资讯日报 | 📋 已有 |
| **LinkedIn** | 英文版数据摘要 | 📋 P2 |
| **Reddit r/china / r/expats** | 真实身份回答具体问题 | 📋 P2 |

### Step 5：追踪验证

| 方法 | 具体操作 |
|:----|:--------|
| **手动测试** | 在 ChatGPT/Perplexity/Claude 搜索目标问题 → 看 Humance 是否被引用 |
| **Google Search Console** | 获取真实搜索词 → 补充问题池 |
| **AnswerThePublic** | 发现更多长尾问题变体 |
| **品牌监测** | 定期搜索品牌名 + 关键词在 LLM 中的出现 |

## 四、输出规范

### 4.1 改造后的文章结构

```
标题：核心关键词 + 覆盖问题范围（≤25字）

【前言 / 背景】
一句话说明这篇文章解决什么问题

【核心问答区】
Q1：[具体问题]
A1：[结构化答案]

Q2：[具体问题]  
A2：[结构化答案]

...（8-10 个 Q&A）

【FAQ Schema】
```json 结构化数据代码

【相关推荐】
同国家/同类型的 3-5 篇文章链接
```

### 4.2 标题规范

- 包含核心关键词 + 覆盖范围
- 示例：`"中国企业在波兰用工：劳动法、最低工资与辞退补偿全解读"`

### 4.3 问题设计原则

- 每个问题控制在 **15-25 个词**（模拟 LLM 用户提问长度）
- 覆盖：是什么、怎么做、多少钱、什么条件、有什么风险
- 包含明确的国家/地区 + 业务场景

## 六、交接

- 需要获取用户搜索词数据：使用 `baidu-ziyuan-collect` 技能
- 需要分析注册用户行为：参考阅读分析报告
- 需要批量改造文章：直接输出 Q&A 格式内容

## 七、边界

- 不要承诺 LLM 一定会引用——AEO 是概率提升，不是确定性结果
- 不要用 AI 批量生成低质内容——100% AI 内容在答案引擎中几乎不起作用
- 不要刷量——多源引用靠真实内容价值，不是数量
