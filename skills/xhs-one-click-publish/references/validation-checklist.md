# Validation Checklist Quick Reference

Pre-publish and post-publish validation items for XHS notes. Run embedded in Stage 4 (0 additional Credit rounds).

## Pre-Publish: Text Quality

- [ ] Title ≤20 characters
- [ ] Title: no generic clickbait (绝了/必看/救命/震惊)
- [ ] Title: ≤2 emoji (0 for B2B notes)
- [ ] Body ≤1000 characters
- [ ] Body: hook → pain → solution → CTA structure
- [ ] 3-6 paragraphs with visible line breaks
- [ ] 3-5 topics (1 broad + 1 niche minimum)
- [ ] No banned words: skip 最/第一/唯一/100%/保证
- [ ] No AI flavor: skip 首先其次最后/值得注意的是/总而言之
- [ ] Has soft CTA (question or discussion prompt)
- [ ] Brand mentioned exactly once, subtle placement

## Pre-Publish: Image Quality

- [ ] 2+ images total (1 cover + ≥1 supporting)
- [ ] Cover: JPG/PNG, 1080×1440 minimum, ≤20MB
- [ ] Supporting: JPG/PNG (not WebP/AVIF), ≥800px shortest side
- [ ] All file paths are absolute and files exist
- [ ] Visual consistency: shared color/style across all images

## Pre-Publish: Metadata

- [ ] Note type: 图文笔记 (not video mode)
- [ ] Visibility setting confirmed

## Post-Publish: Execution Completeness

- [ ] Tab switch confirmed (hasImageInput: true)
- [ ] Image count matches expected
- [ ] Title visible in debug screenshot
- [ ] Body text visible in debug screenshot
- [ ] #topics visible in debug screenshot
- [ ] Publish button click confirmed
- [ ] Result page shows published note (not draft)
- [ ] No error toast visible
