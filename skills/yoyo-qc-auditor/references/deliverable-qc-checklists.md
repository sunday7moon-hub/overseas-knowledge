# 四类产物交付质检清单

> 建立：2026-09-09 · 巴蒂
> 用途：**对外/对内交付前的最后一道关**。对应阿里 7.5 分天花板——"能打开"≠"能发出去"。
> ⚠️ **与 `checklist.md` 的区别**：那份是 **QC Auditor 自己怎么校验 Agent** 的清单；这份是 **四类产物本身** 的质检项。
> 用法：QC Auditor 或任何 Agent 在交付前逐条打勾。**任一 P0 未过 → 阻断，不许发出。**

---

## 通用原则（四类都适用）

| 原则 | 说明 |
|---|---|
| **打开看一眼** | 生成完必须实际打开/渲染一次。截图或渲染失败 = 未通过 |
| **链接可打开** | 每个对外链接必须实测可访问，404/打不开 = P0 |
| **返回 ok ≠ 成功** | 脚本报成功也要回查（按 ID 或按文件字节数验证） |
| **未验证数据必须标注** | 估算值/未核实值显式标注，禁止以"大概"蒙混 |
| **零占位符** | 不得出现 `XXX`、`待填`、`[国家]`、`05 I am the chapter name` 这类模板残留 |

## 一、知识卡片

### P0 阻断项

| # | 检查项 | 判定标准 | 怎么验 |
|:-:|---|---|---|
| 1 | 文案长度 | 正文 **≤100 字**（极简，便于粘群转发） | 数字数 |
| 2 | 分类标签 | 必须含「海外资讯」+ 地区/国家标签 | 看标签行 |
| 3 | 国旗 emoji | 国家对应国旗 emoji 正确，不错配 | 肉眼核对 |
| 4 | 来源可打开 | 附的来源 URL 实测能打开 | curl / 浏览器 |
| 5 | 无模板残留 | 无 `XXX`/`待填`/占位文字 | 肉眼 |
| 6 | 数值有出处 | 出现的每个数字都能追溯到来源 | 抽查 |

### P1 警告项

- 卡片配色符合区域规范（东南亚绿 #006633→#00994D / 欧洲藏蓝 #1E3A5F→#2B5797 / 中东沙漠金 #8B4513→#D2691E / 拉美绿黄 / 北美深靛蓝）
- 尺寸正确：知识卡片 420px 宽；小红书版A 1080px 宽长图；版B 1080×1440（3:4）
- 截图用指定 chromium：`/Users/yoyo/Library/Caches/ms-playwright/chromium-1228/chrome-mac-arm64/Google Chrome for Testing.app/...`（当前 playwright 期望 1234 但系统只有 1223/1228）

### 分渠道附加

| 渠道 | 附加要求 |
|---|---|
| **微信群分享版** | 独立精简模板：**4 段 + 品牌 + humancehr 链接**；**零 Markdown**（粘群直接可读）；与小红书笔记文案严格区分 |
| **小红书版** | 标题 ≤20 字；正文 120-200 字；含 3 个 emoji；结尾引导关注 + 话题标签（#出海 #人力资源 #国家名） |

## 二、PDF 薪资报告（客户向）

### P0 阻断项

| # | 检查项 | 判定标准 | 怎么验 |
|:-:|---|---|---|
| 1 | 三币一致 | local / CNY / USD **三种币种都显示且数值自洽** | 逐行核对换算 |
| 2 | 汇率锁定 | **同一份报告内锁定单一汇率**，同日不同报告间也不跳变 | 查汇率取值日期 |
| 3 | 中文字体 | SimHei 正常渲染，**无方块/乱码/缺字** | 打开 PDF 看 |
| 4 | 版本隔离 | 客户版**不含任何内部批注/内部版水印** | 逐页翻 |
| 5 | 水印 | 水印版含「用友薪福社 + 日期」 | 检查 |
| 6 | 数值来源 | 每个薪酬数值带来源与时效标注 | 抽查 |
| 7 | 未验证标注 | 估算/未核实数值显式标注 | 全文搜"估算/待核实" |
| 8 | 无分页切断 | 表格/段落**没有被拦腰截断** | 翻到每页底部看 |

### P1 警告项

- reportlab 混排 SimHei + Helvetica 无错位
- 页眉页脚齐全、页码连续
- 客户名/国家名无错别字（**最容易翻车的一项**）
- 高危来源一票否决（已在采集侧拦截，此处复核）

### 交付前

- 三个版本（内部 / 客户 / 水印）文件名区分清楚，不发错版本
- 发送是**人工动作**，Agent 只生成不发送（见岗位说明书 A9）

## 三、出海早报

### P0 阻断项

| # | 检查项 | 判定标准 | 怎么验 |
|:-:|---|---|---|
| 1 | 条数 | 每日 **3 条** | 数 |
| 2 | 三方向覆盖 | 法规更新 / 风险预警 / 薪酬支付 **各 1 条**，不缺 | 看分类 |
| 3 | 标题完整 | 用原文**完整标题**，不缩略 | 对比原文 |
| 4 | 链接可打开 | 每条 URL 实测能打开，且是 humancehr.com 域名 | curl |
| 5 | 非系统异常页 | 正文不是 `system-error-try-again` 占位页 | 看正文 |
| 6 | 无竞品 | 来源不含 25 家竞品黑名单 | 比对黑名单 |
| 7 | 无政治敏感 | 不含中国领导人姓名、涉政治议题 | 关键词扫 |
| 8 | 30 天去重 | 三层判定：URL / 标题核心主题 / 关键词主题，30 天内不重复 | 查 memory.md |
| 9 | 禁推内容 | `PUSH_STATUS=3`（禁止发布）**绝不推送** | 查状态字段 |
| 10 | 知识点长度 | 摘要 ≤150 字 | 数字数 |

### P1 警告项

- 发布时间不晚于 09:15
- 三分类展示顺序**随机轮换**，不要固定顺序

### 飞书 post 格式（格式错 = 重做）

| 项 | 要求 |
|---|---|
| 标题 | `今日出海关注 \| 2026.M.DD 周X`（**不是**「慧思出海早报」） |
| 摘要段 | 直接 `🌅 摘要内容...` 一行，**不加 `📌`、不加 `**关键词**` 标签** |
| 每条资讯 | 2 行：行1 = 序号 + 加粗标题；行2 = `🔗` + URL（同一 content 数组元素内） |
| 条目分隔 | 一行空段落 `[{"tag":"text","text":"","style":[]}]` |
| 底部 | **不加任何底部引导行** |

## 使用方式

**QC Auditor 调用时**：
1. 确认产物属于哪一类
2. 逐条过 P0，任一项未过 → **阻断**，登记飞书 QC 台账并通知 Yoyo
3. P1 未过 → 登记为「待确认」，不阻断但必须记录
4. 全部通过 → 输出 `质检通过`，附证据（字数/链接状态/截图/字节数）

**生产 Agent 自检时**：生成完立即按本清单自查，把结果写进产物末尾或日志。
