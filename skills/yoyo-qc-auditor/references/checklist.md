# QC 三层校验清单（Checklist）

> 唯一真相源。QC Auditor 每次校验必须逐层过，不可跳层。
> 每层输出：`通过 / 不通过 / 不适用` + 证据。没有证据的"通过"无效。

---

## Layer 1 · 目标校验（Goal Check）

在 Agent 开工前或接单时执行。

| # | 校验项 | 判定标准 | 不通过后果 |
|:-:|--------|---------|-----------|
| G1 | **目标可验证性** | 有量化验收标准（条数/比例/字段完整率），非"尽量做好" | 退回，要求 Yoyo 明确 |
| G2 | **边界清晰** | 明确做什么 + 明确不做什么 | 补充边界 |
| G3 | **意图一致性** | 与 Yoyo 原始诉求一致，无理解偏差 | 重新对齐 |
| G4 | **越权风险** | 是否涉及对外发布 / 改他人独占表 / 改自动化配置 | 需 Yoyo 显式授权 |
| G5 | **依赖就绪** | 脚本存在、凭据有效（JSESSIONID/token/API）、表结构未变 | 先修依赖再跑 |
| G6 | **幂等性预案** | 重跑会不会产生重复数据？有没有去重窗口 | 补去重机制 |
| G7 | **验收门禁已定义** | 每个子任务都有 gate | 补门禁 |

---

## Layer 2 · 过程校验（Process Check）

执行中/子代理返回后执行。

| # | 校验项 | 判定标准 | 严重度 |
|:-:|--------|---------|:------:|
| P1 | **步骤完整性** | 所有必做环节都执行了，无跳步 | P1 |
| P2 | **门禁真执行** | 校验规则实际跑了，不是口头声称"已校验" | P0 |
| P3 | **静默失败** | API 返回 ok 但数据查不到；报错被 try/except 吞掉 | **P0** |
| P4 | **错误可追溯** | 失败有明确 error 信息，非"失败"两字带过 | P1 |
| P5 | **重试幂等** | 重试未产生重复记录（ID 连续不跳号、无同 ID 双份） | P1 |
| P6 | **来源真实性** | 来源链接可打开；层级符合 6 层优先级；无 AI 编撰 | **P0** |
| P7 | **以法代模** | 合同类：法律条文不得冒充合同模板 | **P0** |
| P8 | **竞品/PR 过滤** | 25 家竞品黑名单 + PR 六层检测已执行 | P1 |
| P9 | **去重窗口** | 30天（早报/关键词）/ 60天（资讯同题）去重已执行 | P1 |
| P10 | **数量如实** | 声称条数 == 实际入库条数 | P1 |

---

## Layer 3 · 结果校验（Result Check）

完成后执行。

| # | 校验项 | 判定标准 | 严重度 |
|:-:|--------|---------|:------:|
| R1 | **数量达标** | 达到目标条数（如资讯 ≥8 可推送） | P1 |
| R2 | **结构完整** | 必填字段非空；正文长度达标（≥300 汉字 / 五段式） | P1 |
| R3 | **分类比例** | 全球动态:法规更新:风险预警 ≈ 1:2:1，三分类全覆盖，法规更新 ≤50% | P1 |
| R4 | **交叉一致** | 飞书条数 == API 入库条数 == 报告声明条数 | **P0** |
| R5 | **ID 连续性** | 资讯 ID 当日连续不跳号；飞书 ID 与 DB INFO_ID 不撞号 | P1 |
| R6 | **交付物真实** | 文件存在且内容非空、非占位符（`system-error-try-again-*`） | **P0** |
| R7 | **去重结果** | 30/60 天窗口内无重复主题 | P1 |
| R8 | **精选合理性** | 精选标记符合 P0 标准（权威来源 + 含数据 + ≥300字） | P2 |
| R9 | **地区/标签覆盖** | 高优地区（东南亚/中东/欧盟）有覆盖；6 个 HR 标签尽量覆盖 | P2 |
| R10 | **日志留痕** | 已写入飞书工作日志 | P2 |

## 严重度定义

| 级别 | 定义 | 处置 | 通知 |
|:----:|------|------|------|
| **P0** | 数据造假 / 静默失败 / 对外发布错误 / 交付物缺失 | 立即阻断，停止对外发布 | **立即通知 Yoyo** |
| **P1** | 流程跳过 / 数量不达标 / 结构缺失 / 重复写入 | 返工，限期修复 | 当日汇总通知 |
| **P2** | 优化项 / 覆盖不足 / 标记不规范 | 登记台账，不阻断 | 仅登记，周汇总 |

---

## 评分规则

起始 100 分，按问题扣分（可扣至 0）：

- P0 问题：-30 / 条
- P1 问题：-15 / 条
- P2 问题：-5 / 条

| 分数 | 结论 | 处置 |
|:----:|------|------|
| ≥ 90 | **放行** | 正常交付 |
| 70–89 | **有条件放行** | 交付 + 登记 P2/P1 待办 |
| 50–69 | **返工** | 退回对应 Agent 重做，最多 2 次 |
| < 50 | **阻断** | 停止对外发布，立即通知 Yoyo |
