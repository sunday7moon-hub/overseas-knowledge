# 邮件发送前检查清单

群发前逐项确认，避免线上事故：

## 1. 图片与资源
- [ ] `邮件-联系慧思.jpg`（企微扫码引导图）已托管到线上 CDN/对象存储，
      所有 `<img src="邮件-联系慧思.jpg">` 已替换为**线上绝对 URL**。
- [ ] 品牌头/文尾无相对路径依赖，纯 HTML 内联样式（邮件客户端兼容性）。

## 2. 占位符
- [ ] `{{unsubscribe_url}}` 保留原样，由 DirectMail（阿里云）发送时自动替换；勿手动填值。
- [ ] 无其他 `{...}` 模板残留变量。

## 3. 文案与合规
- [ ] 落款统一 **Alina（慧思）**（非 Yoyo）。
- [ ] 无"您好 您好："等拼接错误。
- [ ] 文尾含公司主体（北京用友薪福社云科技有限公司）、地址、联系邮箱、退订入口、版权免责。

## 4. 推送节奏（防骚扰）
- [ ] 已用 `scripts/push_scheduler.py` 跑过去重排程，同用户同日 ≤ 1 封。
- [ ] 已建联用户标 `客户阶段=已建联`，其 C 类群发已停止；已转化用户停 A/C。
- [ ] 活跃邮件 A 自活跃日 +3 推送，未抢在注册当天刷屏。

## 5. 凭据与通道
- [ ] 阿里云 DirectMail 凭据已配置（AccessKey + 发信域名已备案）。
- [ ] 发信地址与回复地址一致，SPF/DKIM 已配置避免进垃圾箱。
- [ ] 分批计划已排（参考 `outputs/YYYY-MM-DD 邮件触达分批计划与正文清单.md`），首日小批量灰度观察打开率。

## 6. 监控回采
- [ ] 发送后回采打开/点击率，反哺 C 类分层与 A 周上限调参。
- [ ] 退订用户标记 `触达状态=已退订` 并停止后续排程（`suppressed=True`）。
