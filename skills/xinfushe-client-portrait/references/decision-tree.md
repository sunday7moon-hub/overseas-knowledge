## 一、产品组合漏斗（猎头获客 → 转化留存 → 长线运营）

```
海外在招岗位/招聘难
    │
    ▼ 🔴 主推猎头签约 → 人才到岗
    │
    ├─ 无海外主体 ──────────► 🟡 EOR名义雇主（承接雇佣）
    ├─ 有主体但HR不自算薪 ───► 🟡 Payroll BPO（承接发薪）
    ├─ 外派中方员工 ─────────► 🟡 签证 + 全球商保
    ├─ 招到的是高管/关键岗 ──► 🟡 薪酬体系咨询/Anchor系统
    │
    ▼ 🟢 长线运营
    入职后月度发薪/合规维护/政策更新提醒
    → 人才留存回访 → 业务扩招 → 猎头复购 + 交叉销售
```

## 二、目标客户判定速查

### 必须排除（❌）
| 类型 | 特征 | 排除原因 |
|------|------|---------|
| 纯产品出海 | 只参展/拿贸易订单，海外不设人 | 无雇佣需求 |
| 跨境电商小商家/贸易公司 | 平台卖货或贴牌贸易 | 海外不需要当地员工 |
| 会展短期推广 | 制造业展会推广，短签即回 | 不常驻无长期雇佣 |
| 远程可交付服务公司 | 服务国外客户但国内交付 | 无海外人员 |
| 批量劳务/蓝领外派 | 建筑/工厂工人成批外派 | 需特殊蓝领资质，非猎头/EOR客群 |

### 核心目标（✅）
- 渠道出海（派人发展渠道）或产能/品牌出海（设厂/建团队）
- 行业：新能源与高端制造、互联网与科技、生物医药、消费电子（猎头版图更宽：通信IT/汽车/游戏/跨境物流/SaaS/消费品/智能制造等13类皆可）
- 白领岗位（销售/售前/工程师/管理/技术研发）
- 决策权在国内、To B、注重服务体验
- 多国运营需统一管理

### 边缘（⚠️ 需进一步确认）
- 出海阶段不明的新企业
- 预算极敏感（参考失败案例：EOR成本占工资一半被拒 → 评估是否转RPO/预算教育）
- 老板对海外成本无认知（需先做预算教育）

## 三、产品触发信号速查

### 🔴 猎头主推信号
1. 有海外在招岗位 / 发布过海外JD
2. 表达"招不到人/简历不匹配/offer被抢"
3. 海外扩张动作刚启动（注册子公司/建厂/获海外订单）
4. 本地HR或招聘渠道缺失
5. 快速到岗（急）或批量（多岗多国）需求

### 🟡 EOR转化信号（猎头落地后）
- 招到人但客户无当地实体
- 客户有实体但无雇佣配额/无HR团队

### 🟡 Payroll转化信号
- 客户有实体且已有员工，但算薪/个税社保外包中或想外包

### 🟡 签证/商保转化信号
- 招聘的是中方外派员工（非本地招聘）

## 四、案例库（背书素材）

| 案例 | 客户类型 | 服务 | 亮点数字 | 用途 |
|------|---------|------|---------|------|
| 某生物企业 | 高端生物医学成像设备，脑科学院士创立，2024获美国订单 | 猎头出海美国 | **14天到岗** | 讲速度/避业务受阻 |
| Recurrent AI | NLP对话分析AI企业，21年出海 | 猎头外包海外招聘 | **降40%招聘成本** | 讲成本/补人力短板 |
| 某头部科技企业 | 移动办公套件，出海日本 | EOR 30人同步入职 | 无Local HR合规快速 | 讲EOR全包价值 |
| 某基因检测公司 | 基因测序硬件 | EOR 10国 | 10-30人统一管理 | 讲多国EOR |
| ❌跨境物流 | 3个月建50人团队 | EOR被拒选RPO | EOR成本占工资50% | 教训：先评估预算 |
| ❌机械制造 | 越南招本地BD | 当地猎头被搁置 | 老板无成本认知 | 教训：先预算教育 |

## 五、需要确认的字段清单（线索不足时追问）
1. 出海国家/区域（Q1）
2. 有无当地主体（Q2）
3. 招聘状态与岗位类型（最关键：决定是否猎头主推）
4. 员工构成（外派/本地）
5. 预算与决策人特征
6. 时效要求（急/不急）
