# 合规指南 PPT 克隆器（Compliance Guide PPT Cloner）

## 这是什么

一种「**版式克隆 + 内容替换**」的 PPT 生产模式：不是从空白页新建，而是把一份已定稿的某国合规指南 PPTX 当作**底版**，逐页把文字和表格替换为目标国数据，输出一份视觉 1:1 对齐的新国家指南。

适用场景：出海 HR / 薪福社需要按统一模板批量产出多国雇佣合规指南（如 奥地利 → 西班牙 → 更多国家）。已落地案例：奥地利模板（26 章 + 封面，27 页，16:9，主色 #CC0000）克隆为西班牙 2026 版。

## 何时用

- 用户给了一个 `.pptx` 模板 + 要求「做 XX 国的版本」
- 强调**保留原模板配色、字体、表格布局、页数**
- 数据需准确、标注来源（合规类文档，错误代价高）

不适用于：从零设计全新版式（那用 `pptx-generator`）；产出 Markdown/Word 报告（那用 `huisi-employment-compliance`）。

## 工作流（6 步）

### 第 1 步｜准备模板与调研数据
- 确认输入模板路径（只读参考，不改动）。
- 用 WebSearch 调研目标国 2026 关键合规数据，逐项记录来源（政府令号 / 律所简报 / PwC / BOE / INE 等）。**重点核验**：最低工资(SMI)、标准工时、社保雇主/雇员费率与缴费基数上下限、个税区间、产假/育儿假、试用期、客观/不公平解雇补偿、工签/蓝卡门槛、13/14 薪。
- 遇**权威源冲突**（如某改革是否生效），采取保守可辩护口径并在文中标注「以官方为准 / 推进中」。

### 第 2 步｜提取模板结构
```bash
python scripts/clone_pptx.py --dump --src 模板.pptx
```
输出每页的 `形状名 + 文本`、以及每个表格的 `名称 + 行数/列数 + 各行首列内容`。据此填写 SPEC（形状名必须完全匹配，包括空格）。

### 第 3 步｜填写 SPEC（核心）
编辑 `scripts/clone_pptx.py` 中的 `SPEC`：
```python
SPEC = {
  "TEXTS": {
      1: {"Title 1": "西班牙雇佣合规指南", "Subtitle 1": "2026版"},
      3: {"Text 3": "• 要点1\n• 要点2"},   # \n 换行
  },
  "TABLES": {
      6: {
          "Table 0": [["项目","标准","备注"], ["SMI","€1,221","RD 126/2026"]],
          "Table 1": [["维度","数值"], ["工时","40h"]],
      },
  },
}
```
- 键是 **slide 序号（从 1 开始）**，值是 `{形状名: 内容}`。
- 表格行数**必须等于模板原行数**；多/少都会破坏版式（见第 4 步机制）。
- 文本用 `\n` 表示换行，格式自动从原段落复制。

### 第 4 步｜运行克隆
```bash
python scripts/clone_pptx.py --src 模板.pptx --out 目标国_雇佣合规指南_2026.pptx
```
内置机制（已实战验证）：
- **格式保留**：`_copy_run_format` 深拷贝源 run 的 `<a:rPr>`（字号/粗体/斜体/字体/颜色），并保留段落对齐与层级 → 新文字视觉与原模板一致。
- **表格行列对齐**：`set_table` 先按目标行数与原模板对齐——行数多了 `tbl.remove` 删末行，少了 `_add_table_row` 用末行 XML 深拷贝追加（保留列宽与字形），**绝不**用 `table.rows.add()`（python-pptx 该 API 在克隆场景会报 `'_RowCollection' has no attribute 'add'`）。
- **多表页**：用表格形状名区分（如 `Table 0` / `Table 1`）。

### 第 5 步｜校验
脚本自动打印：
- `ROW/COL MISMATCH: NONE` —— 每页表格行列数与模板完全一致（版式不溢出）。
- `TEMPLATE-COUNTRY LEAKS: NONE` —— 无原模板国文字残留（如奥地利的 ABGB/ASVG/Urlaubsgeld）。
手动补充：无 LibreOffice 时无法渲染预览，靠上述结构校验 + 关键数据抽查替代；若需预览可安装 LibreOffice 转图。

### 第 6 步｜数据复核收尾
- 跑完后逐页核对关键数字（尤其工资阈值、费率、生效日期）。
- 修正发现的过期/错误数据，重跑至校验全绿。

## 常见坑

| 坑 | 现象 | 解决 |
|---|---|---|
| 表格行数超模板 | 自动加行撑破版式 | SPEC 表格行数裁到与模板一致；脚本已支持删多余行 |
| 残留原国文字 | 输出混入 ABGB/ASVG 等 | 填全 SPEC + 校验 LEAKS |
| 颜色丢失/变黑 | 主题色未复制 | 用深拷贝 `<a:rPr>` 而非仅设 `.color.rgb` |
| `table.rows.add()` 报错 | AttributeError | 改用 XML 深拷贝末行方案 |
| 形状名不匹配 | 文字未替换 | 用 `--dump` 拿准形状名（含空格） |

## 数据来源核验清单（2026 合规类）

- 最低工资/14薪：政府公报（西班牙 BOE RD 126/2026；各国对应政令）
- 社保费率/基数上下限：PwC 各国 Employment Tax / 社保白皮书、官方社保机构
- 工时/解雇/产假：律所年度法律更新（Paul Hastings、L&E Global、LegalClarity 等）
- 工签/蓝卡门槛：移民局 + 欧盟指令转化令（如西班牙 PJC/44/2026）
- 税率：税务机关官方表 + 权威税务简报
- **冲突处理**：权威法律源（律所/政府）> 博客；改革「已生效」与否以官方文本为准，不确定则标注。

## 边界

- 结果是合规辅助与对外物料草稿，不替代当地律师个案结论。
- 数据无法当日核验时明确标注「待官方确认」，不用看似精确的内容替代未知事实。
- 不改动输入模板文件；输出为新文件。
