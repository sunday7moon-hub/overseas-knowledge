# 小红书每日爆款笔记推荐

## 定位：只看「当日」的爆款榜

本技能专管**当天**各赛道的热门笔记与单日爆款特征（时效性强、窗口短）。

| 你要做的事 | 该用哪个技能 |
|---|---|
| **今天各赛道什么最火 / 单日爆款特征** | **本技能** ← |
| 长周期趋势、跨时间窗选题分析 | `xhs-research` |
| 贴单条笔记 URL 解析 | `content-analyzer` |
| 生成爆款卡片图 | `xhs-trending-cards` |

## 简介

小红书每日爆款笔记推荐是一款专为内容创作者和营销人员设计的智能工具，帮助用户实时追踪小红书平台当日的爆款笔记数据。

通过简单的关键词查询，你可以：
- 🔥 分类查询当日热门笔记：按美妆、穿搭、美食等分类检索小红书当天热度最高的笔记，快速掌握各赛道头部内容。
- 📁 单日爆款笔记分析：查看单日互动增长最快、曝光飙升的笔记详情，分析其标题、封面、内容结构等爆款特征。
- 📊 各领域当日趋势追踪：监测不同领域的实时热度变化，识别正在起量的内容方向，预判下一波流量风口。
- 🔔 创作灵感生成：基于当日爆款内容，提炼可复用的选题、话术与呈现形式，直接用于你的下一篇笔记策划

适用于品牌方、MCN机构、自媒体从业者、内容策划等需要监测小红书热门内容的场景。

**技术基础**：基于小红书公开内容接口，每日19:00更新昨日榜单数据。

## 功能特性

### 🎯 核心功能

- **🔥 单日爆发榜查询**：获取当日热门笔记TOP50，按分类查询，支持25个垂直领域精准匹配
- **📊 智能规律分析**：生成热门内容分析、爆款标题分析、最高数据作品分析三维度报告
- **📈 多维度数据展示**：完整呈现互动数、点赞、评论、收藏、分享及新增数据
- **🔔 自动订阅推送**：支持每日19:30固定时间推送最新榜单到消息栏

### ✨ 特色亮点

- **⏰ 智能日期适配**：支持指定日期或模糊日期查询，自动按规则匹配近2天数据
- **📤 多格式输出**：自动生成Markdown表格+HTML可视化文件，支持导出PDF/图片
- **🔗 一键跳转**：笔记和作者主页可直接点击跳转，查看原内容更便捷
- **⚡ 无额外门槛**：无需小红书账号、无需API密钥，安装依赖即可使用

## 使用指南

### 基础使用（3步）

#### 1. 发起查询

告诉工具你要查询的分类或关键词（未指定日期则自动按规则匹配近2天数据）：

> 用户：帮我查一下睫毛膏相关的爆款笔记
>
> 助手：正在为你查询化妆美容分类的单日爆发榜数据...

#### 2. 查看完整输出

系统自动输出4项内容（完整流程规范见 [references/core_workflow.md](references/core_workflow.md)）：

| 序号 | 输出内容            | 说明                                         |
| ---- | ------------------- | -------------------------------------------- |
| 1    | 🔥 单日爆发榜       | 含更新时间，展示TOP20数据                    |
| 2    | 📊 单日爆发笔记分析 | 热门内容分析、爆款标题分析、最高数据作品分析 |
| 3    | 📁 HTML页面         | 直接输出可视化页面，支持导出PDF/图片         |
| 4    | 🔔 订阅服务         | 每日19:30推送选项                            |

#### 3. 查看更多数据

默认输出TOP20内容，输入「查看更多」即可获取全部50条内容：

> 用户：查看更多
>
> 助手：为你展示全部50条单日爆发笔记...

---

### 高级使用（4步）

#### 1. 分类匹配规则（内部执行）

系统会根据用户输入自动匹配合适的分类，分类匹配逻辑在执行时内部完成，不直接向用户展示具体映射规则或匹配细节。

如需查看完整匹配规范，请参考 `references/core_workflow.md`。

#### 2. 日期判断规则

- 用户指定了日期 → 直接使用指定日期
- 用户未指定日期：
  - 当前时间 >= 19:00 → 查询**昨日**数据
  - 当前时间 < 19:00 → 查询**前天**数据

#### 3. 数据输出逻辑

| 阶段     | 单日爆发榜 | HTML页面          | 提示                          |
| -------- | ---------- | ----------------- | ----------------------------- |
| 首次输出 | TOP1-20    | TOP1-20           | 数据>20条时显示"查看更多"提示 |
| 查看更多 | TOP21-末尾 | TOP1-末尾（完整） | -                             |

#### 4. 数据一致性保障

- 单日爆发榜表格与HTML页面必须使用相同数据源
- 两个脚本使用相同的API接口，禁止修改接口返回的顺序

## 项目架构

### 目录结构

```
xhs-daily-ranking/
├── scripts/
│   ├── xhs_daily_fetcher.py   # 数据拉取、榜单生成核心脚本
│   └── gen_xhs_html.py        # HTML可视化文件生成脚本
├── references/
│   └── core_workflow.md       # 完整功能流程规范（核心）
├── requirements.txt           # 依赖声明
└── SKILL.md                  # Skill定义文档
```

### 技术栈

- **运行环境**：Python 3.8+
- **依赖库**：requests>=2.28.0
- **输出格式**：Markdown / HTML
- **数据来源**：小红书公开内容接口

### 数据流转

```
用户请求 → 参数校验（日期/分类匹配） → 调用公开接口拉取数据
    ↓
生成Markdown榜单 → 规律分析 → 渲染HTML文件
    ↓
返回4项结果（榜单 + 分析 + HTML + 订阅选项）→ 用户响应
```

## ⚠️ 输出规范（重要）

> 完整功能流程规范见 [references/core_workflow.md](references/core_workflow.md)

### 触发前提（强制，禁止违反）

- **禁止在用户未明确输入查询内容或未订阅时，自动查询和输出热榜信息**
- 只有当用户主动输入关键词、分类名或明确表达查询意图时，才可调用脚本获取数据
- **禁止主动向用户推送热榜数据、禁止在闲聊或无关对话中自动调用接口**

### 四项输出内容（强制执行）

| 序号 | 输出内容            | 要求                           |
| ---- | ------------------- | ------------------------------ |
| 1    | 🔥 单日爆发榜       | 含更新时间，禁止折叠，禁止遗漏 |
| 2    | 📊 单日爆发笔记分析 | 3个模块，禁止折叠，禁止遗漏    |
| 3    | 📁 HTML页面         | 直接输出页面，禁止只输出路径   |
| 4    | 🔔 订阅服务         | HTML页面后立即输出，禁止跳过   |

### 输出格式要求（强制执行）

- **禁止折叠输出**：所有内容必须直接完整输出
- **禁止输出文件**：除HTML页面外，禁止输出任何其他文件
- **输出顺序**：严格按照单日爆发榜 → 单日分析 → HTML页面 → 订阅服务

### 执行脚本命令

```bash
# 获取榜单数据（最多50条）
python scripts/xhs_daily_fetcher.py --keyword "{关键词}" --top_n 50

# 生成HTML页面
python scripts/gen_xhs_html.py --keyword "{关键词}" --top 20   # 首次输出
python scripts/gen_xhs_html.py --keyword "{关键词}" --top 50   # 查看更多
```
