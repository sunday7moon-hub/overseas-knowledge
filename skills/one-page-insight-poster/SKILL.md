# One Page Insight Poster

## 定位与边界

| 输入是什么 | 该用哪个技能 |
|---|---|
| **一段已得的分析结论**（根因 / 数据 / 建议） | **本技能** ← |
| humancehr.com **文章 URL 或选题**（输出 HTML + 截图 + 分享文案） | `country-knowledge-poster` |
| 榜单 / 趋势**数据**（输出 PNG 卡片） | `xhs-trending-cards` |

---


## 何时使用

当用户已得到一段结构化分析（根因、数据、建议），希望把它做成一张**一页纸的说明图**用于：
- 给客户/业务方快速解释现象
- 会议展示或邮件配图
- 社群/公众号内容海报

触发词示例：「做成一页纸」「做个说明图」「整理成一页图」「出个可视化」等。

## 信息准备

执行前先确认（可向用户追问）：
1. 核心结论/标题是什么？
2. 关键数据有哪些（3-4 个最佳）？
3. 原因/问题分几条？建议分几条？
4. 目标阅读对象是谁（客户/内部/社群）？

## 页面结构

按以下模块从上到下排版，保持 880×1400~1450 px 的竖版海报：

1. **页眉**：深蓝背景，白色主标题 + 浅灰副标题；下方加品牌/国旗三色细条。
2. **关键数据条**：3-4 个白色卡片，深色大号数字 + 小字说明，横向等分。
3. **核心判断横幅**：浅色底，左侧红色/主色 pill 标签「核心判断」，右侧一句话结论。
4. **原因/问题模块**：编号卡片（圆圈徽章），每条含标题 + 一句话说明。如有多组，用不同颜色区分模块。
5. **建议模块**：横向 4 列卡片或 2×2 网格，每条一个动作建议。
6. **页脚**：数据来源 + 免责声明小字。

## 设计规范

- **画布**：880×1450 px；背景用极浅灰 `#F7F9FB`。
- **主色**：深蓝 `#14385E`（标题/数据），红 `#D6453D`（警示/问题），金 `#E8A33D`（要点/徽章），白底卡片带浅灰边框。
- **字体**：标题用 `Sarasa Gothic SC` Bold；正文用 `Noto Sans SC` Regular/SemiBold。
- **卡片**：圆角 10-12，padding 14-16，细灰边框，必要时左侧数字徽章。
- **文字**：标题 15-20px，说明 12-13px，数据数字 28-30px。中文行高 1.4~1.6。

## 执行步骤

1. 使用 `ardot-design-core` / `ardot-design-router` / `ardot-poster` 的规则与风格指南。
2. 创建新 Ardot 文件或复用当前文件，建立根 Frame 作为海报容器。
3. 确认中文字体可用（`Sarasa Gothic SC`、`Noto Sans SC`）。
4. 按模块顺序插入：页眉 → 数据条 → 核心判断 → 原因/问题 → 建议 → 页脚。
5. 每一批插入后截图验证，修正文字溢出、对齐问题。
6. 导出 `PNG`（屏幕/社群）和 `PDF`（打印/邮件），放入 `outputs/` 后 `present_files`。

## 注意事项

- 中文字体必须显式设置 `fontName`，否则可能渲染为空或出现字体缺失警告。
- 文本节点建议设置 `width: "fill_container"`，避免中文长文案单行溢出。
- 数据卡避免超过 4 个，建议模块建议控制在 4 条以内，保证一页不溢出。
- 先出图确认整体节奏，再调字号/间距；必要时适当增加海报高度，不要把内容挤到页边。
