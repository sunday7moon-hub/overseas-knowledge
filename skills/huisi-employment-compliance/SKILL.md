# 慧思-海外用工合规评估（Humance Employment Compliance）

## 覆盖范围

技能覆盖六大区域，主要目的地如下（交付时以具体国家/地区当日官方来源为准）：

| 区域 | 主要国家/地区 |
|---|---|
| 东南亚 | 新加坡、马来西亚、泰国、越南、印度尼西亚、菲律宾、缅甸、柬埔寨、老挝、文莱 |
| 欧洲 | 英国、德国、法国、荷兰、意大利、西班牙、波兰、葡萄牙、匈牙利、捷克、瑞典、丹麦、爱尔兰、比利时、卢森堡、希腊、罗马尼亚、瑞士、挪威、俄罗斯（欧洲部分）等 |
| 中东 | 阿联酋、沙特阿拉伯、卡塔尔、科威特、巴林、阿曼、土耳其、以色列、约旦、黎巴嫩等 |
| 北美 | 美国、加拿大、墨西哥 |
| 拉美 | 巴西、阿根廷、智利、秘鲁、哥伦比亚、厄瓜多尔、乌拉圭、巴拉圭、玻利维亚、巴拿马、哥斯达黎加、多米尼加等 |
| 中国及港澳 | 中国内地、中国香港、中国澳门 |

覆盖范围之外的地区：仍可按五维框架评估，但报告须显著标注「超出标准覆盖范围，建议当地律师复核」。

## 用户入口

用户可以直接说：「帮我评估在XX国雇佣XX岗位的合规要求」「在XX国招人要注意什么」「对比本地子公司和EOR雇佣的差别」，或上传现有的招聘 JD、派遣计划文件。

最少需要：

- 目标国家或地区
- 岗位或用工场景（职位、行业、是否派遣/本地招聘）
- 现有企业信息（是否已有当地实体、母国主体、预计员工人数）

可选信息：

- 薪酬预算或现有薪酬结构
- 派遣/本地雇佣的计划安排
- 希望的输出格式（Markdown / Word / Excel）

注意：不要让用户填写内部 JSON；员工编号、身份证号等无关个人信息不设为必填。

## 执行

1. 从用户输入或上传文件提取已确认事实，只追问完成任务所缺的最少信息
2. 执行当日核验目标国政府、移民局、税务、社保、劳动部门等官方来源的现行口径与生效期；无法核验时明确标记「待官方确认」
3. 按五大维度组织评估：**雇佣形式 / 签证与工作权 / 薪酬合规 / 社保税务 / 合同文件**
4. 将已确认信息写入内部临时 JSON 并运行脚本生成标准化报告骨架：

   `python scripts/run.py --input <内部临时JSON> --output <结果.md>`

5. 结合当日核验结果填充报告正文，区分「事实 / 计算参数 / 判断依据 / 待确认项 / 下一步行动」

## 交付

- 用工合规评估报告（五维结构，可直接给客户）
- 风险清单与整改建议（按风险等级排序）
- 慧思服务推荐（可选，当客户有落地需求时推荐 EOR/薪酬/人事托管等）

## 边界

- 不要求内部账号、员工编号或用户手写 JSON
- 动态政策、费率、期限和入口无法从当日官方来源核验时，明确标记「待官方确认」
- 输入不足时输出待补充清单，不用看似精确的内容替代未知事实
- 结果是合规辅助和咨询草稿，不替代当地律师、仲裁机构或主管部门的个案结论
- 只处理任务所需的最少个人信息，不索要无关身份证号、账号密码或完整病历
- 不得依据性别、年龄、婚育、籍贯、民族、健康等敏感属性作出不当人员决策
