## 〇、区域覆盖清单

技能标准覆盖六大区域；以下为各区域主要目的地，用于识别是否在标准覆盖范围内：

| 区域 | 主要国家/地区 | 备注 |
|---|---|---|
| 东南亚 | 新加坡、马来西亚、泰国、越南、印度尼西亚、菲律宾、缅甸、柬埔寨、老挝、文莱 | 出海热门：新加坡常作为区域总部/EOR 落点 |
| 欧洲 | 英国、德国、法国、荷兰、意大利、西班牙、波兰、葡萄牙、匈牙利、捷克、瑞典、丹麦、爱尔兰、比利时、卢森堡、希腊、罗马尼亚、瑞士、挪威、俄罗斯（欧洲部分）等 | 英国已收录案例；欧盟国家注意 GDPR 与跨境派遣 A1 |
| 中东 | 阿联酋、沙特阿拉伯、卡塔尔、科威特、巴林、阿曼、土耳其、以色列、约旦、黎巴嫩等 | 阿联酋注意工资保护系统（WPS）；沙特注意本地化用工（Saudization） |
| 北美 | 美国、加拿大、墨西哥 | 美国已收录案例（NY/NJ）；墨西哥注意 IMSS/INFONAVIT 强制缴纳 |
| 拉美 | 巴西、阿根廷、智利、秘鲁、哥伦比亚、厄瓜多尔、乌拉圭、巴拉圭、玻利维亚、巴拿马、哥斯达黎加、多米尼加等 | 巴西劳动法严格（CLT）；智利/秘鲁已参与多个中企项目 |
| 中国及港澳 | 中国内地、中国香港、中国澳门 | 中国内地：社保五险一金、个税、劳动合同法；中国香港：强积金（MPF）、雇佣条例；中国澳门：社保制度与劳工法 |

**覆盖范围之外**：仍可按五维框架评估，但报告须显著标注「超出标准覆盖范围，建议当地律师复核」。

**案例收录原则**：每个国家/地区完成当日官方核验后，按「五维要点 + JD 审查红线 + 合规措辞示例」格式收录，并注明核验日期与来源链接；未收录国家以本清单 + 通用五维核对表为准。

## 一、美国（纽约州 / 新泽西州为例）

### 1.1 五维要点

| 维度 | 要点 |
|---|---|
| 雇佣形式 | 中国主体无美国实体时须设立实体（EIN/州注册）或经 PEO/EOR 雇佣；业务岗建议 W-2 员工，慎用 1099 独立承包人（NY/NJ 反 misclassification 执法严） |
| 签证与工作权 | 招聘广告应写 `须持有在美国合法工作的权利（US work authorization）`；需担保则走 H-1B/L-1（成本高、周期长） |
| 薪酬合规 | **强制薪资范围披露**：纽约州 NY Labor Law §194-b（2023-09 起，4+员工）须写 min-max 范围，「面谈/competitive/DOE」违规；新泽西州 S2310（2025-06-01 起，10+员工）须薪资范围+福利概述；NYC 本地法同要求。Offer 金额须落在 posted range 内并留市场依据记录 |
| 社保税务 | FICA 社保税、联邦/州所得税预扣、州失业保险，均须有美国雇佣主体才能缴纳；2026 新泽西最低时薪 $15.92 |
| 合同文件 | 禁止询问薪资历史（NY/NJ 均禁）；NY 州/NYC/NJ 均须提供带薪病假；NYC Human Rights Law / NJ LAD 比联邦法覆盖更广（NJ LAD 1 人以上雇主即适用） |

### 1.2 JD 审查红线清单

- [ ] 薪资写「面谈/面议/competitive」→ 必须改为数字薪资范围（+福利概述，NJ）
- [ ] 出现性别表述（即使「男女均可」）→ 删除
- [ ] 硬性学历（如「本科及以上」）→ 加「或同等行业经验」，避免 disparate impact
- [ ] 面试不得索要出生日期/毕业年份（ADEA 审查风险）
- [ ] 未注明工作权要求 → 补 `US work authorization`

### 1.3 合规措辞示例

```
Base $70,000–$95,000/年 + 销售提成；提供医疗/牙科/视力、带薪病假、401(k)。
大学本科及以上学历，或具有同等行业经验的成熟业务人员。
须持有在美国合法工作的权利（US work authorization）。
```

## 二、英国（英格兰/威尔士/苏格兰适用）

### 2.1 五维要点

| 维度 | 要点 |
|---|---|
| 雇佣形式 | 中国母公司无英国实体须设立实体或经 EOR；英国员工走 PAYE 预扣所得税 + 雇主 NIC；符合条件员工须 auto-enrolment 养老金（雇主最低 3%） |
| 签证与工作权 | **禁限「必须是英国公民」**（Equality Act 2010 国籍歧视）；合规写法：`须持有在英国合法工作的权利（Right to Work in the UK），本岗位不提供签证担保` |
| 薪酬合规 | 2026-04-01 起最低工资：21+ £12.71/h、18–20 £10.85/h；底薪+佣金折算不得低于此线；佣金规则须书面（ERA 1996）；英国暂不强制招聘广告披露薪资范围 |
| 社保税务 | PAYE + 雇主 NIC（2026-04-06 umbrella 新规对 EOR/中介责任）；产假等法定付薪 £194.32/周（2026-04 起） |
| 合同文件 | 入职第一天须给书面雇佣条款（written statement）；2026-04 起 day-one 病假（SSP £123.25/周）、day-one 陪产/育儿假；2026-10 起第三方骚扰责任；数据须符合 UK GDPR |

### 2.2 JD 审查红线清单

- [ ] 年龄区间（如「30–50岁」）→ 整段删除（直接歧视，几乎无法抗辩）
- [ ] 「英国公民/UK Passport」→ 改为 Right to Work + 不提供签证担保
- [ ] 「企业零签证合规风险」类表述 → 删除（坐实国籍筛选意图）
- [ ] 指定专业限定 → 改为「专业不限，相关专业或同等从业背景优先」
- [ ] 性别表述 → 删除
- [ ] 业绩凭证口径 → 允许多种形式（合同/对账单/客户证明），避免间接歧视
- [ ] 驾驶/出差要求与工作相关即可保留，注意为残障候选人提供合理调整

### 2.3 合规措辞示例

```
须持有在英国合法工作的权利（Right to Work in the UK）；本岗位不提供工作签证担保。
本科及以上学历，专业不限；时尚商业管理/纺织品工程/国际贸易/市场营销等专业或同等从业背景优先。
底薪 + 销售提成（佣金制度于入职前书面确认；底薪不低于英国国家最低工资标准）。
```

## 三、通用五维核对表（任何国家）

| 维度 | 必核验项 |
|---|---|
| 雇佣形式 | 本地实体直雇 vs EOR/PEO vs IC；责任主体与税务影响 |
| 签证与工作权 | 本地招聘工作权核验方式；派遣员工签证类型/担保义务；无担保意愿的合规表述 |
| 薪酬合规 | 最低工资/时薪（当日核验）；薪资结构折算；薪酬透明披露义务 |
| 社保税务 | 雇主/雇员缴纳项目及比例（当日核验）；所得税代扣；跨境支付与 ODI/外汇合规 |
| 合同文件 | 书面条款、试用期、通知期、解雇程序；数据保护；佣金/绩效书面化 |

## 四、阿联酋（联邦 / 迪拜为例）【2026-08-13 当日核验】

> 核验来源：Federal Decree-Law No. 33 of 2021（劳动法）；Ministerial Resolution No. 340 of 2026（WPS，2026-06-01 生效）；MoHRE 官方口径及 2026 年合规指南。

### 4.1 五维要点

| 维度 | 要点 |
|---|---|
| 雇佣形式 | 大陆公司（mainland，经 MoHRE 监管）与自由区公司（自贸区当局自管，DIFC/ADGM 走普通法法院）双轨；中国主体无实体时可用 EOR/PEO；Federal Decree-Law No. 33 of 2021 认可 6 种就业模式：全职/兼职/临时/弹性/远程/工作共享 |
| 签证与工作权 | 工作签证须雇主担保并注册劳动合同（数字合同，MoHRE 或自由区当局）；自由区自办签证；Green Visa 技术工人（AED 15,000/月+本科）可自担保不依赖雇主；离职/解雇后宽限期内须离境或转雇主（具体天数当日核验） |
| 薪酬合规 | **无普遍联邦最低工资**（第 27 条授权内阁设定，从未对外籍行使）；2026-01-01 起**阿联酋国民**私营部门最低**基本工资** AED 6,000/月（不含津贴，2026-06-30 前须合规，逾期暂停新工签+每月 AED 6,000 罚款）；外籍按合同约定+工签 salary benchmark（学历挂钩软门槛）；**WPS 强制电子发薪**：Ministerial Resolution No. 340/2026（2026-06-01 生效）——上月工资须下月 1 日付清，85% 按时支付门槛，逾期 2 日警告/5 日暂停新工签/11 日罚款（Cabinet Resolution No. 21 of 2020）/16 日自动登记劳资纠纷/21 日资产保全+负责人旅行禁令（50+ 员工）；现金、支票、非 WPS 转账不合规 |
| 社保税务 | **无个人所得税**；企业利润 9% 企业所得税（2023-06 起）；阿联酋国民：GPSSA 雇主约 12.5%+雇员 5%（比例当日核验）；外籍员工不缴 GPSSA；迪拜外籍员工强制储蓄计划私营推广进度（当日核验）；雇主须承担招聘/签证/体检/居留费用，**禁止向员工收取**（第 33 条明确） |
| 合同文件 | 固定期限合同（2022-02 起废除无限期，最长 3 年可续签）；试用期≤6 个月且不可延长/重复（雇主解雇提前 14 天通知）；终止通知期 30–90 天；年假 30 天/年（第一年 2 天/月）、病假 15 天全薪+30 天半薪+45 天无薪、产假 60 天（45 全薪+15 半薪）、陪产假 5 天；服务终了金按**基本工资**计（前 5 年 21 天/年，之后 30 天/年）；反歧视+男女同工同酬（第 4 条）；扣薪上限 50%/月；竞业限制≤2 年须写明地域/岗位/期限 |

### 4.2 JD 审查红线清单

- [ ] 薪资必须拆分「基本工资 + 津贴」（服务终了金、国民最低工资均按基本工资计算）
- [ ] 不得写「限阿联酋公民」类表述（第 4 条禁止国籍歧视；国民积极区别对待仅限 Emiratisation 政策框架内）
- [ ] 试用期≤6 个月、不可重复，写明解雇提前 14 天通知
- [ ] 竞业限制≤2 年，且写明地域范围、岗位类型、期限
- [ ] 合同写明发薪日（下月 1 日前）+ WPS 电子支付；不得承诺现金发薪
- [ ] 不得要求员工承担签证、体检、居留或招聘费用

### 4.3 合规措辞示例

```
基本工资 + 住房/交通津贴（明确拆分；服务终了金按基本工资计）。
工资通过 WPS 批准渠道电子支付，发薪日为每月 1 日前。
固定期限劳动合同（最长 3 年可续签），试用期 3 个月，终止通知期 30 天。
```

### 4.4 待官方确认项

- GPSSA 现行缴费比例（国民）与是否有新政
- 离职/解雇后的居留宽限期现行天数
- 迪拜外籍员工强制储蓄计划对私营部门的适用时间表
- 阿联酋个人数据保护法（PDPL）执法现状
