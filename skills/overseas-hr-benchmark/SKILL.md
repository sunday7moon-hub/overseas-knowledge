# 海外HR服务与工具市场对标调研

把"竞品功能调研 + 自有资产映射 + 落地优先级"沉淀成可复用流程。本技能来自 Deel/NACSHR/1EOR/BIPO/Knit/Oyster/Remote/Multiplier 八家对标实战，结论已验证，可直接引用。

## 适用场景
- 规划 humancehr.com / Anchor 工具市场，决定先做什么获客工具
- 对标 Deel、NACSHR、1EOR、BIPO、Knit 万领钧、Oyster、Remote、Multiplier 等竞品
- 判断哪些工具/能力最适合做成 MCP 级服务（AI Agent 可调用）
- 任何"竞品功能调研 + 自有资产映射"类任务

## 核心方法论（可复用六步流程）

### Step 1 选对标样本：覆盖矩阵（避免单一市场偏差）
至少覆盖四种商业模式，缺一不可：
1. 全球 EOR·产品驱动（Deel / Remote / Oyster）
2. 区域合规·自检工具（NACSHR 美国各州）
3. 白标工具平台（1EOR，验证"工具即可售卖产品"）
4. APAC/本土 EOR（BIPO，补东南亚/中东盲区）
5. 中企出海·华语服务（Knit 万领钧，客群重合度最高）
> 加 Oyster(内容引擎/按国落地页)、Remote(API/MCP优先)、Multiplier(预算型+签证140+国) 补"内容/分发/签证"维度。边际收益递减点：再堆 Papaya/Safeguard/Velocity 等只重复确认同一套工具，不必扩——五家足以支撑结论。

### Step 2 抓取与多平台交叉验证
- 用 WebFetch 抓各站 /tools、/resources、/calculator、/country-guides、/academy 等；被墙用 WebSearch 补。
- 把工具按"类型"对齐（不是按站点），用"双方各自投入强度 1-5"打分。
- 重合度 ≥4/5 的类型 = 跨市场验证的通用刚需，结论最硬。

### Step 3 人气/价值代理信号（页面无真实用量时）
页面通常无评分/使用次数，用代理信号反推：
- 编辑标记 HOT（代表已验证核心刚需）/ NEW（代表扩张方向，非已验证）
- 免费比例（免费=引流手段，非价值本身）
- 跨区域复刻次数（同一工具类型在多州/多国反复出现=核心刚需模块）
- 注册/订阅门槛（设门槛=留资/转化环节）

### Step 4 映射自有产品/用户画像/资产
- 用 Anchor SOP 售前判断树（国家→主体→员工→外派/Local→白领/蓝领）当映射骨架
- 每个工具映射到：对应 Anchor 产品 + 客户阶段 + SOP 识别信号 + 优先级
- 关键：工具 = 把销售已在做的判断"产品化/自助化"，并自动执行"非目标过滤"（蓝领/劳务外派直接挡掉，解放顾问产能）

### Step 5 区域适配矩阵
按 欧洲/东南亚/美洲 拆分，标注每区最佳获客工具 + SEO 词 + 客户价值：
- 欧洲（强保护强监管）：AI招聘合规自检(GDPR/AI Act蓝海) + 离职赔偿计算器 + 工签 + 国别指南
- 东南亚(🔴高优)：国别指南/合规日历(SEO金矿) + 最低工资/薪资对照 + EOR成本 + 外派成本栈+商保
- 美洲（北美复杂+拉美高社保）：EOR成本 + 工签(美H1B/L1/加) + 国别指南(各州/省差异)

### Step 6 MCP 化优先级判定（三维度评分）
综合分 =（数据资产就绪度 + MCP天然适配度 + 战略差异化）/ 3，满分5：
- 数据资产就绪度：现有资料能否直接支撑（如法规库/资讯日报/飞书表）
- MCP天然适配度：是否 AI Agent 可实时查询/推送（而非纯静态页）
- 战略差异化：竞品是否还没做成 MCP（蓝海）
> 最优先 = 法规监控/合规哨兵（Compass）：三项全满，且已规划 Coze 7节点 + MCP 5工具、coze-transit(SSE) 待配。次优先 = 合规自检（同搭法规库）。暂缓 = 工签/EOR成本/薪资基准（数据广度不足，需补至 1EOR 1705国 / Knit 自助查询级别才能 MCP 化，否则 Agent 查出来是空的/错的）。

## 已验证结论（可直接引用，无需重算）
- **5/5 满验证必做工具**：工签资格检查器、EOR/雇主成本计算器、国别指南/落地页、最低工资/薪资基准
- **4/5**：监管警报/法改、福利/商保。**3/5**：全球移动/外派、雇佣错误分类。低成本钩子：BIPO 汇率换算器、Knit HR词典/政府机构目录
- **支撑数据**：Deel 150+国 / 40000+客户 / $20B+合规薪资 / 90+NPS；1EOR 2300+岗位 / 1705国薪资分位；BIPO 170+市场；Knit 172国 / 4000+客户 / ¥40亿+薪资 / 60+自营主体；Anchor 150+国 / 12分支 / 600+团队 / 1000+客户 / 70+国指南 / Anchor系统+YonGPT
- **Knit 资源中心结构**（成本计算器+薪资查询+工签+国别指南+法改/日历）是 Humance 工具市场最佳模板——第一个中企出海+华语+顾问跟进标杆
- **获客分层**：引流层(免费SEO: 国别指南/薪资对照/工签/AI合规/警报) → 留资层(注册门槛: 成本计算器/赔偿/外派/商保) → 转化层(出海准备度自检路由 → 顾问)

## 红线与注意事项
- **竞品新闻源黑名单**：Knit 等在"出海资讯日报25家竞品黑名单"中，作工具产品对标可用，但禁止其 PR/AI 内容进资讯流
- **禁 AI 编撰**：法规/薪资数据必须溯源政府/权威媒体/真实底层数据，宁可少数据
- **地区错位**：NACSHR 的 HOT 全在北美（Humance 低优），主战场放东南亚/中东/欧盟
- **信号非真实数据**：排名是代理估算，上线后用真实埋点（访问/完成率/留资转化）反推
