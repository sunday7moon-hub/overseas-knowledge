# 客户信息收集与主动推进（Client Intake & Push）

**用途**：报告已交付第一版（市场带宽）后，如何主动向客户索取信息、把「市场 band」升级为
「可直接定预算 / 下招聘需求」的版本。**主动 push 场景专用**——不是等客户来问。

核心逻辑（一段话）：**先给礼物 → 指出差距 → 明确清单 → 给回报 → 约动作**。
第一版报告是免费的可信度凭证，不是终点；用 4 项信息缺口作为下一次沟通的抓手。

---

## 一、客户需提供的信息（三层：缺 → 好 → 优）

### 第 1 层｜必给（缺了无法落位，对应内容门禁 A4）

| # | 信息项 | 为什么必须要 | 没给的后果 |
|---|---|---|---|
| 1 | **内部职级体系 / 薪档表**（职级名称 + 档位 + 带宽） | 唯一能把市场 band 映射到客户职级的输入 | A4 缺口无法销账，HR 拿到报告无法落位 |
| 2 | **岗位权责边界**：管几个国 / 是否带团队 / 汇报线 / 单国盘量 | 决定取市场中位（P50）还是中上分位（P75-P90） | 带宽定偏，可能招不到人或超付 |
| 3 | **年度招聘节奏**：共招几个 / 先招哪国 / 时间点 | 排分国招聘优先级与顺序 | 只能给一张静态价目表，给不了方案 |
| 4 | **薪酬结构意向**：固浮比 / 住房津贴 / 外派补贴 / 是否含 relocation | 直接影响 OTE 与雇主成本测算 | 雇主成本只算社保税费，不含津贴，失真 |

### 第 2 层｜加分（给了方案更准）

| 信息项 | 用途 |
|---|---|
| 现有同岗在职人员薪资（脱敏可） | 内部公平性校准，避免新人倒挂老人 |
| 候选人来源偏好（本地华人 / 中国外派 / 第三国） | 决定市场池与溢价水平 |
| 当地用工方式（EOR 代理 / 自设实体 / 名义雇主） | 决定雇主成本口径（EOR 有服务费，自设有注册成本） |
| 竞争对手对标对象（抢谁的候选人） | 校准分位，做针对性定价 |

### 第 3 层｜一次说清就够（我方可自行调研，无需客户给）

平均月薪、社保率、个税率、最低工资、签证门槛、离职金规则——**这类我们自己查，别问客户**，
问了显得不专业。仅在无法取得权威源时才回问确认。

## 二、话术模板（可直接粘，零 Markdown 适配微信）

### 2.1 微信短版（推荐：4 段内，手机一屏可读完）

```
{X 总}您好，上周发您的{中东七国／东南亚五国}两份区域销售经理薪酬带宽报告，
您那边看着顺手吗？

那两份是纯市场口径——外面这个岗位什么价、各国差多少。但您这边 RSM 招聘
覆盖国家多、每个市场打法不一样，光有市场价还不够落地。

要把它变成您能直接拿去定预算、给 HR 下需求的版本，还差四样控维自己的信息：
1. 内部职级体系/薪档（把市场价落到您的职级上）
2. 这个岗的权责边界：管几个国、带不带团队、汇报给谁（决定取市场中位还是中上分位）
3. 年度招聘节奏：共招几个、先招哪国（我们帮您排分国优先级）
4. 薪酬结构意向：固浮比、住房津贴、外派补贴给不给

您把这些发我，我们免费补一版「带内部职级映射 + 分国招聘优先级」的方案，约 {X} 个工作日。

另外提醒两个会影响预算的数：以色列雇主成本约为薪资的 21%、马来西亚外籍公积金
10 月起强制 2%，报告里都标了，建议让财务一起看。

要不要本周约 30 分钟，把这几项过一遍？
```

## 三、拿到信息后我方交付什么（承诺要与能力对齐）

| 客户给的信息 | 我方补出的内容 | 对应脚本/章节 |
|---|---|---|
| 职级体系 | 市场带宽 → 客户职级的映射表 | 新增「职级对标」节，销 A4 |
| 权责边界 | 分位取值说明（为何 P50 还是 P75） | 摘要分位口径 |
| 招聘节奏 | 分国招聘优先级表 + 建议顺序 | 决策矩阵「建议顺序」列 |
| 薪酬结构 | 固浮比与津贴并入 OTE / 雇主成本 | 1.2 雇主成本与到手测算 |
| 用工方式 | 雇主成本口径修正（EOR 服务费 / 自设成本） | `EMPLOYER_COST` 表按客户口径覆盖 |

## 四、主动推进节奏（Push Cadence）

| 时点 | 动作 | 钩子 |
|---|---|---|
| Day 0 | 交付第一版市场带宽报告（免费） | 建立可信度，声明「这是市场口径，不是终版」 |
| Day 2-3 | 发信息清单（本文档话术） | 4 项信息缺口 + 明确回报 |
| Day 5-7 | 未回则催一次，附「已有人拿到职级映射版」同侪效应 | 稀缺感 |
| Day 7+ | 约 30 分钟对齐会，逐项过 | 降低客户填表成本，现场收集 |
| 收到信息后 X 日 | 交付第二版（含职级映射 + 优先级 + 预算） | 兑现承诺，为下一岗位创造入口 |

**关键提醒**：4 项信息里，第 1 项（职级体系）是**必须**的，后 3 项可以退而求其次用我方假设先做、
标注「待客户确认」。**不要因为客户没给全就停摆**——先出一版带假设的，用「假设已标注待确认」推动客户纠正，
比等客户填表快得多。
