# 客户向薪酬带宽报告生产（A9 薪酬带宽报告官）

为出海客户提供"岗位薪酬带宽 / 人工成本"报告。本技能强调**数值可信**与**发布前质检**，核心教训来自 2026-09 卫华集团·墨西哥蒙特雷报告事故。

> 编排与质检边界：本技能只做生产，发布前必须经 **A8 质量校验官（yoyo-qc-auditor）** 放行（见 yoyo-agent-swarm 越界禁令表 §0.1 + 门禁第 39 行：不给客户出含未验证数值的报告，P1 告警）。

## 冷启动：新任务从这里开始（2026-09-14 增）

**不要翻工作区脚本、不要依赖历史对话**——本 skill 自带完整可运行资产，新会话直接调取。

**为什么必须走这套（背景，勿删）**

2026-09-14 之前，工具函数散落在工作区的客户专用脚本里（`cowave_v2_build.py` 等把**工具层与客户数据层混在一起**），
新任务只能复制粘贴或翻历史对话；而 skill 里原有的 `report_starter.py` 停留在 8 月版本
（色值还是已弃用的 `#2E5AAC`、水印函数**没有 title 回写**、`fix_currency` 只认 `¥`）——
照着它做会直接生成旧样式报告。结果是**每接一个任务都要在一个新对话里重建工作流**。
本套资产把工作流固化：工具与数据分离，模板自带可运行示例，验收脚本一把梭。

## 强制门禁（违反即 QC 拦截）

1. **汇率必须单一常量 + 程序化换算**
   脚本顶部定义 `RATE` 常量与 `cny(mxn, nd)` 换算函数，所有"约合 CNY"由程序计算。
   **禁止**把汇率散落为字面量（卫华初版把 `0.3972` 写死在 17 处单元格 + 元数据 + 脚注，9/11 复核时全表同比例偏高且无从改起）。
2. **汇率必须多源校准 + 带时间戳**
   生成前用权威源校准（汇率插件 / Ria / CurrencyConvert / mid-market），取交叉中值，写入
   `1 MXN = 0.3955 CNY（2026-09-11 18:50 实时中间价）` 形式。
   **禁止**"实时"伪标注——脚本内若无实时抓取，时间戳不得手填（卫华初版标 18:57 实为手填，且脚本无任何 fetch）。
3. **三币统一**：local(MXN) + CNY + USD 三栏并列，禁用 emoji / 几何符号。
4. **交付件与中间产物隔离**（原「双版本同源」，2026-09-14 随命名规范改写）
   交付件**只有一个文件**：`..._客户版.pdf`（含水印）。水印用**叠加层**生成——
   先 build 到 `/tmp/xxx_base.pdf`，再由 `make_watermark()` 输出到交付路径并**删除临时基础版**。
   **不可**对同一个被 `build()` 消费过的 `story` 二次 build——reportlab 的 `build()` 会消费流对象，
   二次复用会得到空文档（卫华初版水印版仅 976 字节即此坑）。
   ⚠️ **落盘后必须确认临时基础版（无水印）已删除**：工作区曾残留 9 份无水印中间产物，
      与交付件同名、仅少一层水印，是**误发风险源**（2026-09-14 全量清理）。
      生产脚本须遵循「临时基础版 → 水印 → 删基础版」三步，不得把基版留在工作区。
5. **对外发布前过 A8 QC**：数值类变更须经 Yoyo 确认后回写；未验证数值不得交付客户。
6. **只交付客户版（2026-09-14 Yoyo 定规，即刻生效，优先级最高）**
   每份报告**只产出客户版**（及其叠加层水印版）。**不再生产内容不同的「内部版 / 交付侧底稿版」**。
   - 内部视角内容（谈判锚点、对客话术、搜寻池、竞品情报、候选人评估底稿）**不再单独成册**；
     必要时在客户版内以**中性表述**承载，或走对话/口头交付，不落额外 PDF。
   - 客户版**禁词表**因此成为硬门禁，命中即返工（见门禁 3 与「客户版禁词」小节）。
   - 命名只剩**一类**：`<主体>_<岗位>_<地区><N>国薪酬带宽报告_客户版.pdf`。
     **文件名不带 `_水印版`**（2026-09-14 Yoyo 定规：所有交付件都含水印，标注冗余）；也不带 `_内部版`。
   - **覆盖**：本规则优先于本文件其他位置出现的"内部版/双版本/水印版"表述。
7. **客户可见面不得出现交付侧标注（2026-09-14 Yoyo 定规，命中即返工）**
   `客户版` 是**我方对交付物的称呼**，不是给客户看的标签。客户翻到「密级：客户交付版」「…报告（客户版）」
   只会觉得奇怪。以下 **5 个客户可见面**逐一核查，全部不得含 `客户版 / 客户交付版 / 内部版 / 交付侧 / 底稿`：

   | # | 客户可见面 | 典型病灶 | 处理 |
   |---|---|---|---|
   | 1 | 封面副标题 | `中东七国 · 客户交付版` | 只留中性信息（地区/城市串） |
   | 2 | 封面元信息表 | `['密级','客户交付版']` | **整行删除**（该字段纯内部标注；客户版无需自述密级） |
   | 3 | 每页页眉 | `…薪酬带宽报告（客户版）·2026.09.01` | 去括号后缀，保留 `主体 · 岗位 · 日期` |
   | 4 | **PDF 元数据标题** | 未设 `title` → 阅读器标签页退化成**文件名**（含 `_客户版`） | `SimpleDocTemplate(title=...)` 写正式标题，并确保水印叠加后**元数据不丢** |
   | 5 | 水印文字 | `二六三·客户版·2026.09.01` | 用 `用友薪福社 <日期>` |

   **例外**：**文件名**保留 `_客户版.pdf`（门禁 6 命名规范，Yoyo 明确定过）——文件名与正文可见面是两回事。

   ⚠️ **元数据是易漏项（2026-09-14 实测）**：`make_watermark()` 用 PyPDF2 重建页面会**丢掉源 PDF 全部元数据**，
     导致标题为空、阅读器显示文件名。必须在水印叠加后用 PyMuPDF 回写：
     `d = fitz.open(dst); md = d.metadata or {}; md.update({'title': title, 'author': '用友薪福社'}); d.set_metadata(md); d.save(tmp)` 再 `os.replace()`。
     （**不要**用 PyPDF2 3.0.1 的 `add_metadata()`——它对键格式挑剔，会刷 8 条 `Incorrect first char in NameObject` 警告且写入无效。）
     `make_watermark(src, dst, text, title=None)` 已按此实现，各报告脚本传 `title=` 即可。

   核查脚本（发布前必跑）：本门禁已并入一把梭自检 `pdf-report-layout/scripts/qc_client_pdf.py`，
   一条命令同时查 5 个可见面 + 字形 + 禁词 + 水印 + 页码 + 串区（FAIL 时退出码 1，可直接给 A8 QC Agent）：
   ```bash
   python skills/pdf-report-layout/scripts/qc_client_pdf.py *_客户版.pdf --color "#1f4f8f"
   ```
   ⚠️ 顺带纠偏：**emoji 不能靠 emoji 黑名单查**——`⛔` 这类字符在 PDF 里已变成 `U+0000` 并渲染成**空框**，
   黑名单扫不到；必须用字形能力检测（见 pdf-report-layout「SimHei 字形能力权威表」）。
   2026-09-14 实测即由此揪出 SOLAMODA 英美版 p5、华伽 p3 的 `⛔️` 空框缺陷。

8. **内容维度自查（2026-09-14 控维体检新增——门禁 1–7 保证「不出错」，本条保证「有用」）**
   数值无误 + 排版干净 ≠ 客户能拿去做决策。交付前逐项核对 A1–A7：

   | # | 维度 | 合格判据 | 常见缺口 |
   |---|---|---|---|
   | A1 | 雇主总成本 | 汇总为**雇主附加率**（社保雇主部分 + 离职金年计提）并给出**雇主年成本**列：<br>`年成本 = 月度总包中值 ×（12 + 法定奖金月数）×（1 + 附加率）` | 费率散列在各国「驻地基准」行让客户自己加总；或**直接套本地雇员费率**（新加坡 CPF 17%、马来 EPF 13%、卡塔尔 14%）→ 外籍口径下高估 |
   | A2 | 薪酬结构 | 明确基础/浮动构成比例，含住房津贴、年终奖；**写区域通则一次性说明**，逐国块不重复 | 只给「基础月薪 + 月度总包 OTE」两个孤立数字 |
   | A3 | 个税净得 | **累进税国家必须**提示净得（无个税国家豁免），以「估算有效税率」+「估算净得」两列入表 | GROSS 口径下只字不提净得，客户误以为到手 |
   | A4 | 职级对标 | 带宽映射到客户内部职级/薪酬架构档位 | 只有市场分位，HR 无法落位（**需客户提供职级体系，无法代填**）|
   | A5 | 有效期 | 标注「数据有效期 3–6 个月」 | 无 |
   | A6 | 参照系密度 | **每国**都有同构参照项（平均月薪等），来源标注粒度一致 | 部分国家有、部分缺 |
   | A7 | 溢价口径 | 说明行业溢价**是否已含**在带宽数字内 | 写了溢价幅度，没说含没含 |

   **⚠️ 「雇主成本与到手测算」是标准章节（1.2 节）**，五列：
   驻地 / 雇主附加率 / 法定奖金 / 雇主年成本 / 估算个税有效税率 / 估算净得。
   调库：`employer_table(COUNTRIES, EMPLOYER_COST)` + `employer_stats(ec, olo, ohi, cur)`（见 `salary_report_kit.py`），
   数据侧填 `EMPLOYER_COST` 字典（`rate` / `bonus` / `tax_lo` / `tax_hi` / `cost`）。

   **⚠️ 三条硬口径（控维返工实证）**
   1. **必须按外籍雇员口径**。本地雇员费率不等于外籍费率：新加坡外籍不缴 CPF（本地 17%）、
      马来外籍 EPF 仅 2%（2025.10 起，本地 12–13%）、卡塔尔外籍完全不缴 GRSIA（本国籍雇主 14%）。
   2. **封顶类项目要折算成岗位实际比率**，不能填名义费率：泰国 SSO 名义 5% 但封顶 THB 750/月，
      在 THB 13 万月薪上实际只有 0.5%；马来 SOCSO 1.75% 封顶 RM6,000。
   3. **海湾国家无社保但有离职金**（沙特 4.2% / 阿联酋·卡塔尔 5.8% / 巴林 4.2%+3% GOSI / 阿曼 4.2%+1% PASI），
      少数国家另有法定奖金（菲律宾 13 薪、印尼 THR 各 1 个月）——**漏掉即低估年成本**。

   **⚠️ 「成本指数」≠「雇主年成本」**：指数只反映薪资水平，不含雇主附加成本差异，
   必须在表下显式写明「换算预算以雇主年成本列为准」。否则客户会拿指数做预算换算——
   控维中东版巴林指数 76（比沙特低 24%），但雇主年成本只低 28%+ 差异来源不同，比例并不一一对应。

   一键自检（与排版门禁互补，两条都要跑）：
   ```bash
   python skills/client-salary-band-report/scripts/content_lint.py *_客户版.pdf --watch "比价,外籍常驻"
   ```
   覆盖：缺口红旗（**逐国定位**）/ 版本内重复句 / 跨版本逐字相同长句 / 章级篇幅失衡 / 高频套话 / 封面页眉页码。
   判据细节与改法见 `references/content-review.md`。
   ⚠️ 内容缺口属**设计选择而非错误**，脚本默认不判 FAIL（`--strict` 才返回 1）；但 **A1–A3 优先级最高**——缺了客户无法把报告换算成预算。
   ⚠️ 结构侧同理：同一建议不要在「结论卡 / 决策矩阵 / 地区小结 / 方案建议」里说四遍；决策矩阵的「推荐」列要么给权重依据，要么改条件式表述。

## 生产流程

1. **A9 取数 / 多源校准**：岗位薪资对标（本地招聘站 / ERI / TalentUp / SalaryExpert 等，按薪资源可信度分级表筛高危源）、法定成本（IMSS/INFONAVIT 费率、UMA、最低日薪、PTU、工时）、汇率校准。
2. **生产 PDF（单一交付件）**：build 到临时基础版 → 叠加对角水印 → 输出
   `<主体>_<岗位>薪酬带宽报告_客户版.pdf` → **删除临时基础版**。
   文件名**不带** `_水印版`（水印为交付必备，不写入文件名）。
   **不产出内容不同的内部版**（见门禁 6）；内部视角内容改为在中性表述内承载或口头交付。
3. **A8 质检放行**：逐格反算"约合 CNY = 本币 × RATE"一致性、汇率来源/时间戳核验、字段完整性、
   **水印已叠加**、**工作区无无水印残留**；输出 QC 评分与结论。
4. **交付**：`present_files` 呈现，必要时写飞书工作日志。

## 已知坑（血泪案例）

**卫华集团·墨西哥蒙特雷（2026-09-04 首版 → 2026-09-11 校准重产）**
- 初版硬编码 `0.3972`（9/4 标注价，实际 9/4 mid-market≈0.3974 基本准），但**未做多源校准、未过 QC、未走 Agent 编排**，直接单脚本出 PDF。

## 多国报告结构规范（2026-09-14 控维 RSM 案例沉淀）

**拆分原则**：候选驻地 ≥6 个，或横跨 2 个以上地缘区域时，**按地区拆成独立报告**，不做「全球一张表」。
- 控维案例：原 7 国混装（沙特/阿联酋/哈萨克/乌兹别克/印尼/马来/新加坡）→ 拆为
  「中东七国」（沙/阿联酋/卡塔尔/科威特/以色列/巴林/阿曼）+「东南亚五国」（新/马/泰/菲/印尼），
  每份只出客户版（当时的内部版已按 2026-09-14 门禁 6 废止），中亚两国移出。
- 理由：客户按区域做决策，跨地区混排会稀释结论；单报告 ≤7 国才能保证每国都有一个完整小节。

**成本指数锚点**：每份报告在**地区内**选锚点国 = 100（中东取沙特、东南亚取新加坡）。
**不写跨地区桥接句**（2026-09-14 修正）：报告是独立交付物，客户可能只拿到其中一份，
「另一份报告以 XX = 100」这类指代会造成困惑。只声明本报告基准 + 提示「与区外市场不可直接混用」。

**四层标题体系**（PDF 内标题、文件名、页眉三处必须同构）：

| 层级 | 格式 | 示例 |
|------|------|------|
| 封面主标题 | 岗位（缩写）+ 地区国数 + 薪酬带宽报告 | 区域销售经理（RSM）中东七国薪酬带宽报告 |
| 一级章 | 中文数字 + 顿号 + 主题（**不带地区限定词**，封面上已声明） | 一、执行摘要 ／ 三、驻地决策矩阵 |
| 二级节 | 章号.序号 + 全角空格 + 主题 | 1.1　中东七国带宽总览 |
| 国别块 | 章号.序号 + 国家（城市）｜定位｜成本指数 N | 2.1　沙特（利雅得）｜基准驻地｜成本指数 100 |
| 文件名 | 客户_岗位_地区国数薪酬带宽报告_客户版.pdf（**不带「水印版」**） | 控维通信_区域销售经理_中东七国薪酬带宽报告_客户版.pdf |
| 页眉 | 公司 · 岗位（缩写）\| 地区 \| 版本 · 日期 | 控维通信 · 区域销售经理（RSM）\| 中东 \| 客户版 · 2026.09.14 |

**总览表 5 列定式**（已实测：6 列方案在 7 国 × 长数字下必然断行）：

```
驻地 | 基础月薪（本币） | 月度总包 OTE（本币） | 年成本（≈¥ 万元） | 成本指数
```

- 跨币种比价靠 **年成本（≈¥ 万元）** 列完成（= OTE 中值 × 12 × 汇率 ÷ 10000）。
- **不要**把 ≈¥ / ≈$ 塞进总览表：IDR「36,300,000–58,000,000」、ILS「108,252–142,975」这类长数字
  在 9pt 下需 ≥22% 列宽，13 列格塞不下就被迫换行（出现「58,000,00 / 0」断字）。
- 逐国 ≈¥ / ≈$ 换算放到**国别块内**展示，总览表只承担横向比价职能。
- 表头主动写 `<br/>` 控制换行（如 `月度总包 OTE<br/>（本币）`），不要指望自动折行好看。

## 地区报告自洽性（硬门禁，命中即返工）

拆成多份地区报告后，**每份必须完全自洽**——不得出现任何非本地区国家/币种/机构。
2026-09-14 控维事故：东南亚版封面「数据口径」写成了「海湾六国无个税…以色列个税 10-50%」，
根因是**封面元信息与第五章数据来源写成了跨地区共用的硬编码常量**，两个地区共用同一份字符串。

**必须按 cfg['key'] 分地区取值的四处（其余文案均已是 per-region）：**

| 位置 | 中东版 | 东南亚版 |
|------|--------|----------|
| 封面「数据口径」 | 海湾六国无个税；以色列个税 10-50% 累进 | 五国均个税累进，最高档 24-35% |
| 来源表「薪资」 | …GulfTalent…（中东招聘平台） | …Jobstreet…（东南亚招聘平台） |
| 来源表「宏观」 | 沙特 GASTAT / 阿联酋 MOHRE / 卡塔尔 PSA / 科威特 PACI / 以色列 CBS / 巴林 LMRA / 阿曼 NCSI | 新加坡 MOM/CPF / 马来 LHDN/EPF/SOCSO / 泰国 劳工部/SSO / 菲律宾 DOLE/BIR/SSS / 印尼 劳工部/BPJS |
| 来源表「汇率」 | 海湾币种按官方钉住汇率折算 | 东南亚币种取同日实时值 |

**做法**：建一个 `REGION_META = {'me': {...}, 'sea': {...}}` 字典，上述四处全部改为
`REGION_META[cfg['key']]['xxx']`，禁止在 `build_client()` 里写字面量。

**交付前跑串区扫描**（比肉眼看更可靠）：
```python
ME_KW  = ['沙特','阿联酋','迪拜','卡塔尔','科威特','以色列','巴林','阿曼','利雅得','海湾']
SEA_KW = ['新加坡','马来','吉隆坡','泰国','曼谷','菲律宾','马尼拉','印尼','雅加达']
foreign = ME_KW if '东南亚' in fname else SEA_KW   # 取另一地区的词表
hits = {k: text.count(k) for k in foreign if text.count(k)}
# 客户版必须为 {} —— 命中即说明有硬编码串区
```

**封面元信息标签值勿重复**：`['成本基准', '成本基准：以新加坡 = 100 为锚点']` 会渲染成
「成本基准 ｜ 成本基准：以新加坡…」，值里不要再带一遍标签，写「以新加坡 = 100 为锚点」。

## 客户版禁词表（硬门禁，命中即返工）

内部版取消后，内部视角只能靠**客户版自身表述**把关。发布前必跑：

```python
BAN = re.compile(r'与客户确认|建议客户|客户目标|客户反馈|客户诉求|客户原话|口径对齐|'
                 r'对客话术|对客沟通|客户预算|确认预算|招聘执行建议|我方锚点|谈判杠杆|底稿|交付侧')
```

**改写对照**（左禁止 → 右中性）：

| 内部视角（禁止） | 客户版可用的中性表述 |
|------------------|----------------------|
| 与客户确认口径后重报价 | 口径明确后可进一步收敛区间 |
| 建议客户选择迪拜驻地 | 若以区域统筹为优先，迪拜方案更匹配 |
| 客户目标档为 8-15 年 | 本报告主力经验档为 8-15 年 |
| 我方锚点 / 谈判杠杆 | 删除；转为「报价区间说明」 |
| 招聘执行建议（整章） | 删除，不另设章节 |
| 交付侧底稿 / 交付节奏 | 删除；如需排期走对话沟通 |

> 备注：`对客话术` 若作为**章节标题**会命中禁词——客户版不得设该章节。
